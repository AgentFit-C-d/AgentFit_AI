# Profile 필드 해석 확인

상태: 2026-10-01 사용자 답변 대기. 현재 실제 평가는 동결된 기존 기준으로 완료한다. 이 문서가 기존 gold나 점수를 변경하지 않는다.

## 확인이 필요한 이유

실제 의미 품질은 구문 검증과 별개이며, 에이전트가 작성한 임시 정답은 사람 확인이 필요하다. 필드별 DeepSeek 비교에서 제품 용도 기능과 Docker 근거가 제외됐다. 또한 기존 임시 gold에는 ORM이 backend에 포함된 반면, `candidate_field_semantics.py`의 explicit-v1은 언어·프레임워크·런타임 중심으로 서술돼 있다. 모델 오답과 평가 기준의 모호함을 구분해야 한다.

## 질문

| 항목 | 현재 비교 또는 정의 | 확인할 제품 의도 |
|---|---|---|
| 기술 목록에 명시된 제품 동작 | 제품 동작이 명시되면 기능 후보로 인정하는 임시 기대값 | 기술 목록이어도 동작을 추출할지, 별도 기능 요구사항만 허용할지 |
| 공식 Docker 이미지 제공 | 지원 배포 방식으로 인정하는 임시 기대값 | 지원하는 방식도 deployment에 담을지, 실제 채택 운영 환경만 담을지 |
| 명시적으로 채택한 ORM | gold에 포함되지만 내부 필드 정의는 제한적으로 해석될 여지가 있음 | backend에 ORM 등 서버 구현 기술을 포함할지 |

## 답변 처리

- 위 세 답변은 필드 해석에 대한 사람 확인이다. 전체207개 임시 정답에 대한 사람 검토로 표시하지 않는다.
- 진행 중인 GLM 실행, 기존 DeepSeek 결과, 기존 gold 및 source/code freeze는 수정하지 않는다.
- 정의 변경이 필요하면 별도 버전으로 명세·영향·회귀·새 평가를 준비한다. 기존 결과의 점수를 소급해 좋게 바꾸지 않는다.
- 미답변 상태에서도 현재 고정 비교와 독립적인 로컬 작업은 계속한다. 새 기획서 일반화·사람 수정 부담·실제 Spring·운영 검증은 별도로 남는다.
