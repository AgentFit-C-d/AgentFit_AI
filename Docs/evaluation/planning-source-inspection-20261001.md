## 개인정보와 자료 보존

- 05/06의 팀원 이름, 07의 작성자 이름·학번, 10의 작성자 표기를 로컬 검토용 텍스트에서 제거했다. 제거 위치·종류와 원문 블록/변환문 해시를 별도 보존했다.
- 이름·학번은 정규식 탐색만으로 모두 발견되지 않았다. 본문 읽기와 미리보기로 추가 확인했으며, 이미지에서 추출될 개인정보는 후속 OCR 결과에서도 다시 검수해야 한다.
- 원문·미검수 추출문·렌더링·개인정보 값은 Git에 추가하지 않는다. 메타데이터와 검수 보고서만 기록한다.
- MD 검토용 입력은 원래 줄바꿈을 보존한다. 초기에 문단 구분을 위해 줄 사이 공백을 늘린 `inspection-v1/*.txt`는 최종 입력이 아니다.
- 원문 10개의 SHA-256은 획득 기록과 그대로 일치한다. 새 문서에 대한 모델 호출은 0회다.

## 중복과 평가 자격

후보 탐색 전 커밋 `56afcc8`의 specs/Docs/work에서 새 저장소명·원문 SHA-256 문자열을 검색한 결과 일치 파일은 0개다. 이는 해당 범위의 식별자 중복 검사이며 전체 내용의 의미 중복이나 모델 사전학습 노출 부재를 증명하지 않는다.

현재 6개(01~04/09/10)는 텍스트 범위의 임시 정답 준비가 가능하다. 4개(05~08)는 그림/표/구간 변환 검수가 더 필요하다. 후보를 성능이 낮다는 이유로 제외하거나 쉬운 문서로 대체하지 않는다. 향후 이 자료의 결과로 코드·프롬프트를 튜닝하면 해당 노출 범위를 기록하고 최종 검증용으로 재사용하지 않는다.

모든 문서는 아직 **최종 holdout 확정 전**이다. 원문 대응·변환·정답 작성·사람 검토·사전등록이 끝나야 평가할 수 있다. `human_reviewed=false`, `model_evaluation_allowed=false`를 유지한다.
