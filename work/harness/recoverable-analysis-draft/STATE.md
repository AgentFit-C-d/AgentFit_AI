# 상태

- 목표: 실패한 분석에서도 구조·근거 검증을 통과한 제안만 안전하게 보존하고 확인이 필요한 필드를 분리하는 선택형 AI 내부 실험.
- 근거: 지난 비교의 Solar 실패 13건은 판단 상태 4, 수정 재검토 반복 4, 후보 부족 1, 리뷰 형식 1, 시간 초과 3. 새 Solar 초안 실행은 20건 중 정답 11, 내용 오류 5, 초안 생성 실패 4.
- 결정: 기본 `analyze()`·공개 Profile·Spring 저장 계약은 유지. 실패 복구형 결과는 성공이나 저장 완료가 아니다. 사용자는 선택형 내부 실험 방향을 승인했다.
- 현재: 사용자가 명세·계획과 직접 구현을 승인했다. 선택형 복구 분석과 합성 20건 평가를 구현·실행했다. 기본 분석기·공개 Profile·Spring 저장 계약은 변경하지 않았다.
- 검증: 최종 코드 단위 테스트 408건과 `git diff --check` 통과. 최종 합성 20건(run3)은 기존 실패 13건 중 4건을 확인용 초안으로 전환했고, 제안 필드 12개와 질문 28개를 남겼다. 기존 성공의 감지된 오확정 2건, 60초 관측 지연 초과 4건, 의미상 근거 검증 부재로 안전 관문 실패. 실사용·기본값 승격은 보류한다. 세부 수치와 세 번의 독립 실행 해석은 `specs/ai-developer/04-analysis-provider/recoverable-analysis-draft/validation.md`에 있다.
