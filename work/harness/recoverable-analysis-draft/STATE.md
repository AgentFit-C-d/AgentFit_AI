# 상태

- 목표: 실패한 분석에서도 구조·근거 검증을 통과한 제안만 안전하게 보존하고 확인이 필요한 필드를 분리하는 선택형 AI 내부 실험.
- 근거: 지난 비교의 Solar 실패 13건은 판단 상태 4, 수정 재검토 반복 4, 후보 부족 1, 리뷰 형식 1, 시간 초과 3. 새 Solar 초안 실행은 20건 중 정답 11, 내용 오류 5, 초안 생성 실패 4.
- 결정: 기본 `analyze()`·공개 Profile·Spring 저장 계약은 유지. 실패 복구형 결과는 성공이나 저장 완료가 아니다. 사용자는 선택형 내부 실험 방향을 승인했다.
- 현재: 사용자가 명세를 승인했고 구현 계획을 작성했다. 계획 검토·실행 방식 확인 후 구현한다.
- 검증: 기존 selected 제약 및 원문 수정 실험 결과를 읽고 반복 설계를 피했다. 새 코드·API 실험은 아직 실행하지 않았다.
