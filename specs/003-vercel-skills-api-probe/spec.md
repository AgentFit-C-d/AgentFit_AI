# Feature Specification: Vercel skills.sh 인증 시험

**Feature Branch**: `feature/vercel-skills-api-probe`
**Created**: 2026-09-28
**Status**: 로컬 구현 완료, 실호출 미검증
**Input**: Vercel을 테스트 용도로 사용해 skills.sh API의 실제 인증·검색 동작을 확인한다. Full Stack 코드는 변경하지 않는다.

## User Scenarios & Testing

### User Story 1 - 실제 검색 인증 확인 (Priority: P1)

개발자는 Vercel에 연결된 시험 환경에서 검색어 하나로 skills.sh의 제한된 검색 결과를 조회하고, 인증이 실제로 성공했는지 확인한다.

**Why this priority**: 현재 AI 검색 어댑터는 고정 응답으로만 테스트되었고 실제 인증 가능성이 미확인이다.

**Independent Test**: 시험 환경에서 유효한 검색어를 입력해 실제 skills.sh 응답의 상태와 후보 ID를 확인한다.

**Acceptance Scenarios**:

1. **Given** OIDC가 활성화된 Vercel 프로젝트와 허가된 시험 호출, **When** 검색어를 제출하면, **Then** skills.sh의 실제 검색 성공 여부와 제한된 후보 정보가 표시된다.
2. **Given** OIDC 토큰이 없거나 무효할 때, **When** 검색을 시도하면, **Then** 인증 실패로 구분하고 토큰을 노출하지 않는다.

### User Story 2 - 시험 경계 보호 (Priority: P2)

시험용 호출자는 임의의 공개 사용자가 이 프로브를 반복 호출하거나 인증 정보를 조회할 수 없음을 확인한다.

**Independent Test**: 호출 권한이 없거나 잘못된 입력이면 외부 검색을 호출하지 않고 거부하는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 시험용 접근 비밀이 없는 호출, **When** 프로브를 요청하면, **Then** 외부 API 호출 없이 거부된다.
2. **Given** 과도한 검색어 또는 결과 개수, **When** 프로브를 요청하면, **Then** 제한 오류가 반환되고 외부 API 호출은 일어나지 않는다.
3. **Given** 외부 API의 장애나 제한 응답, **When** 프로브를 요청하면, **Then** 실패 종류만 반환하며 원본 오류 본문·인증 정보는 공개하지 않는다.

### Edge Cases

- 외부 검색은 정상적으로 완료됐지만 후보가 0개다.
- Vercel OIDC 기능이 꺼져 있거나 토큰 발급이 실패한다.
- skills.sh가 401·429·5xx 또는 비정상 JSON을 반환한다.
- 접근 비밀 또는 OIDC 토큰을 설정·로그·응답에 노출하려는 실수가 발생한다.

## Requirements

### Functional Requirements

- **FR-001**: 프로브는 Vercel이 발급한 요청 시점의 OIDC 토큰으로 skills.sh 검색 API에 인증해야 한다.
- **FR-002**: 프로브는 접근 비밀이 맞는 시험 호출만 외부 검색으로 전달해야 한다.
- **FR-003**: 프로브는 검색어와 반환 개수를 작게 제한하고 전체 목록 수집을 수행하지 않아야 한다.
- **FR-004**: 프로브는 검색 성공·빈 결과·인증 실패·호출 제한·외부 장애를 구분해야 한다.
- **FR-005**: 프로브는 OIDC 토큰, 접근 비밀, 외부 원본 오류 본문을 응답·로그·버전 관리 파일에 남기지 않아야 한다.
- **FR-006**: 프로브 결과를 검증 Catalog 항목 또는 최종 추천으로 취급하지 않아야 한다.
- **FR-007**: 실제 외부 호출과 모의 응답 테스트의 결과를 구분해 기록해야 한다.
- **FR-008**: Full Stack 파일과 기존 공개 서비스 계약을 변경하지 않아야 한다.

## Success Criteria

### Measurable Outcomes

- **SC-001**: 연결된 Vercel 시험 프로젝트에서 유효한 검색어로 실제 검색을 1회 이상 성공시키고 응답 상태·시각·후보 수를 기록한다.
- **SC-002**: 인증 누락, 접근 거부, 잘못된 입력, 외부 오류의 고정 사례에서 외부 호출 여부와 안전한 결과가 기대값과 일치한다.
- **SC-003**: 시험 실행과 코드 검토에서 토큰·접근 비밀이 응답·로그·커밋 파일에 남는 사례는 0건이다.

## Assumptions

- 이 기능은 운영 추천 경로에 포함하지 않는 일회성 인증 검증용이다. AI 추천 모듈과 Full Stack 서비스는 변경하지 않는다.
- Vercel 프로젝트 및 OIDC 설정, 시험 접근 비밀은 구현 승인 뒤 준비한다. 프로젝트 생성·배포 전에 별도 외부 영향과 비용을 확인한다.
- 실제 호출을 수행할 수 없는 환경에서는 코드·모의 테스트만 완료로 표시하고 SC-001은 미검증으로 남긴다.
