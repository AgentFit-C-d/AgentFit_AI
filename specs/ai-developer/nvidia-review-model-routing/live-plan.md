# DeepSeek 검토 경로 실제 비교 계획

## 목적과 근거

이전 고정 진단 실행에서는 DeepSeek 추출·분류11회 뒤 첫GLM 검토가HTTP5xx로 종료됐다. 이번에는 검토 모델을 DeepSeek4.1Flash로 명시해 동일 공개 자료·정답·채점에서 분석 완주 여부와 품질을 측정한다. 기본 서비스의 모델은 바꾸지 않는다. 결과를 보기 전에 이 계획을 고정한다.

기존GLM 실행은 Profile이 없는 실패1건/미실행29건이다. 이를 완전한 짝 비교나 모델 일반 성능의 기준으로 취급하지 않는다. 처리 시간·완주·임시 정답 일치/누락/잘못된 제안/미평가를 구분해 보고한다.

## 선행 조건과 고정

- 구현 코드 `a28254a370d7c93df447200b994c295aa01d1415`와 동일한 코드/의존성을 유지한다. 최종 독립 리뷰와 이 코드의 정확한 원격CI 성공을 확인한 뒤 실행한다. 리뷰 수정이 필요하면 이 기록과 새freeze를 실제 호출 전에 다시 고정한다.
- variant `nvidia-deepseek-review-v1`, 진단활성, DeepSeek 추출·분류·검토·기능 단계. 모델별 기존 요청정책/프롬프트 유지.
- freeze `f5e1f64b667a075046680182dba86456417af1894304916813377e61ccd3eba5`, evaluator `c8a023265e50ecc1715d9acbc5a070e368ee55c03f368e29b28cc2a60a00d4c5`.
- 공개10문서·문서당3회·임시gold207개를 그대로 사용한다. 새로운holdout으로 표시하지 않으며 `human_reviewed=false`, `release_gate_passed=false`다.
- 기존gold·세결과폴더·이전freeze를 보존한다. 실행 중 코드·모델·원문·정답·채점을 수정하지 않는다. 상태/보고 문서만 갱신한다.

## 권한·예산

사용자가 현재계정의 두NVIDIA모델 무료API 및 무료한도 초과 시 자동결제 없는 거절을 확인했다. 기존 확인파일 `E:/AgentFit/output/independent-profile-v1/nvidia-free-access-20261001-user-confirmation.json`을 읽기전용으로 사용한다. 도구가 계정화면이나 청구를 조회한 것은 아니다.

- 동시평가1개, 분석요청최대30회, 요청당1800초·최대64모델호출.
- 전체최대1920모델호출·관찰16시간, 자동재시도0·유료0·배포0.
- 1920은 이 실험의 보수적 호출 예약 상한이며 실제 무료잔여량이 아니다. 이전 실험 사용량도 잔여할당량으로 환산하지 않는다.
- 무료확인의 기존 만료 `2026-10-01T17:32:45.423911+00:00`를 연장하지 않는다. 한도·제공자오류·기한·만료 시 새 요청을 중단하고 유료대체/충전/자동재시작을 하지 않는다.
- 개인 문서는 보내지 않는다. 기존 승인된 공개문서만 사용한다. API키는 기존안전로더→worker stdin으로 전달하며 출력·로그·Git에 기록하지 않는다.

## 실행 순서

1. 같은 실행 핸들 또는 실제 프로세스 상태로 기존실험이 종료됐고 동시평가가 없음을 확인한다. 새코드freeze·오프라인preflight10/207·무료범위를 검증한다.
2. 생성전용 `E:/AgentFit/output/independent-profile-v1/runs-deepseek-review-a28254a/`가 존재하지 않는지 확인하고, 검증된CLI를1회 시작한다. `--call-diagnostics --review-model deepseek-ai/deepseek-v4.1-flash --live`와 기존env/access파일·새output을 사용한다.
3. 실행핸들을기록하고 같은핸들을 관찰한다. 관찰timeout이나일시적조회오류를 terminal로 오해하거나 실행을 중복 시작하지 않는다.
4. 정상종료/중단 후 모든terminal행과started-only, 진단의 모델·단계·실제호출수·오류·시간을 검증한다. 실패도 누락 분모에 포함하고 미실행은 따로 기록한다. 진단 unavailable을0호출로 표현하지 않는다.
5. 결과 보고와STATE를commit/push한다. 실제데이터·키·원문·Profile·원본응답은 추가기록하지 않는다. 문제를관측한경우 그근거로만 다음보완계획을세운다. 새문서일반화·사람수정량·실제Spring/운영은 독립된미완료관문이다.

실제 실행은 이 문서 작성만으로 시작된 것이 아니다. 핸들·CI·시각·집계는 후속 live-result.md와STATE에 기록한다.
