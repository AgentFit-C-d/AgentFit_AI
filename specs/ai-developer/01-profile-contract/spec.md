# Feature Specification: AI Profile 후보 검증

**Created**: 2026-09-25
**Status**: 구현 기준
**Parent Feature**: [Project Document Analysis](../../001-project-document-analysis/spec.md)

## 목적

문서 분석 결과를 저장 후보로 넘기기 전에 Profile 필드의 구조, 미정값, 근거 위치를 검증한다. 검증 실패는 기존 확인 Profile을 변경하지 않고 안전한 실패로 처리한다. 이 기능의 결과는 사용자 확정값이나 DB 저장 성공이 아니다.

## 사용자 시나리오와 인수 기준

### US1 — 일관된 Profile 초안 후보 (P1)

분석 결과의 10개 필드가 공통 계약과 일치해야 Spring Boot에 초안 후보로 전달될 수 있다.

1. 모든 필드가 정확한 타입으로 존재하면 값, 필드별 출처, 미확정 목록을 일관되게 계산한다.
2. `null`은 미정, 빈 배열은 명시적 없음으로 구분한다.
3. 필드 누락·추가·잘못된 타입·빈 문자열·한도 초과는 검증 실패로 처리한다.

### US2 — 문서와 대조할 수 있는 근거 (P1)

문서에서 확정했다고 주장하는 값에는 처리 중인 텍스트의 유효한 위치 근거가 있어야 한다.

1. 알려진 값의 각 항목은 최소 한 근거 구간에서 실제로 확인할 수 있다.
2. 범위를 벗어나거나 값과 맞지 않는 위치, 알려진 값의 근거 누락은 검증 실패다.
3. 미정값에는 근거를 붙이지 않는다. 검증된 결과는 원문 인용 없이 위치만 남긴다.
4. 위치는 Unicode code point 기준으로 시작 포함·끝 제외다.

## 기능 요구사항

- **PV-FR-01**: 10개 필드와 각 타입을 모두 검증한다. 단일 문자열 필드는 `project_name`, `project_type`, `domain`, `database`, `deployment`이며 나머지는 문자열 배열이다. 각 필드는 `null`을 허용한다.
- **PV-FR-02**: 단일 문자열과 배열 항목은 공백만 허용하지 않고 최대 200 code points, 배열은 최대 30개다.
- **PV-FR-03**: 출처는 값이 `null`이면 `UNKNOWN`, 그 밖에는 `DOCUMENT`로 계산한다. 이 기능은 사용자 수정 출처 `USER`를 만들지 않는다.
- **PV-FR-04**: 미확정 필드 목록은 값이 `null`인 필드에서 계산한다. 모델이 제시한 미확정 목록을 신뢰하지 않는다.
- **PV-FR-05**: 각 근거 위치는 현재 문서의 유효한 code-point 범위이고 해당 값의 원문 표현을 포함해야 한다. `null` 필드에는 근거가 없어야 한다.
- **PV-FR-06**: 실패 결과는 고정 오류 코드와 필드명만 제공한다. 문서 내용, 인용문, Credential 또는 모델 원본 응답을 오류에 포함하지 않는다.
- **PV-FR-07**: 검증 결과는 메모리 데이터다. 이 기능은 DB·파일 저장이나 공개 성공 상태를 만들지 않는다.

## 경계와 제외 범위

- 위치와 문자열의 일치는 **의미상 확정**을 증명하지 않는다. 부정·후보·과거/다른 대상·상충 정보의 의미 판단은 [근거·의미 검증](../05-evidence-validation/README.md)과 별도 평가에서 다룬다.
- FastAPI 내부 HTTP 경로, Spring Boot 저장, PDF 추출, Provider 호출, 실패 원본 응답 7일 보관은 이 작은 기능의 구현 범위 밖이다.
- 합성 정답 사례는 [starter-cases.json](../02-evaluation-fixtures/starter-cases.json)을 사용한다. 세 사례는 전체 품질 목표를 대표하지 않는다.

## 성공 기준

- 시작 사례 3건에서 기대 Profile 값·출처·미확정 목록이 모두 일치한다.
- 구조 오류, 근거 누락·불일치, 미정 근거 잔존을 각각 거부한다.
- Unicode 보조 문자 앞뒤의 근거 위치가 code-point 기준으로 맞는다.
- 검증 실패 메시지에 입력 문서나 모델 원본 내용이 포함되지 않는다.
