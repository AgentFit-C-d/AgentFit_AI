# 구현·검증 계획

1. 선행 수정과 작업 트리 확인 후 `feature/frozen-role-guidance-b`에서 진행한다.
2. 기존 기록과 변경 전 실행 파일 해시를 새 결과 폴더에 보존한다.
3. 현재 B 요청 및 저장 B 응답 검사부터 추가해 기존 A 상수에서 실패를 확인한다.
4. 서비스 상수 하나를 동결 B 문자열과 정확히 같게 교체한다.
5. 기존 격리 실행기를 재사용해 과거 A 요청 검사를 과거 코드로 옮긴다.
   현재 v3 회귀는 저장 분류 결과 이후 경계를 검사한다. 현재 B 분류 요청은
   별도 전송 경계 테스트로 검사하며 옛 응답을 새 전체 실행으로 표현하지 않는다.
6. 전체 네 종류 회귀와 원본 보존·제품 코드 diff를 확인한다.
7. 오프라인 결과 및 다음 실제 문서 평가·병목 측정 순서를 문서화하고 종료한다.

이 작업은 사용자가 명시적으로 승인한 문자열 통합 및 테스트 구성 변경이다.
추가 서비스 계약·검증 단계·복구 도구는 만들지 않는다.
