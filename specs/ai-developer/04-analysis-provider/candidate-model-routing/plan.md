# 구현 계획

1. `AnchoredAnalyzer`에 후보 모델·키·테스트 전송기 옵션을 추가하고, 후보 생성 단계의 송신기만 교체한다. 입력 민감 정보 검사와 모델 응답 검증을 유지한다.
2. 기존 가짜 전송기로 모델별 요청 라우팅·호출 수·기본 경로 회귀 테스트를 먼저 실패시킨 뒤 구현한다.
3. 안전 평가 CLI에 후보 모델 옵션을 추가한다. Solar와 NVIDIA 호출을 함께 세고 모델별 결과를 계획 파일에 기록한다.
4. `Q-001` 단일 호출을 먼저 관찰한다. 구조·품질이 개선될 여지가 있으면 합성 20건으로 확대한다. 원문·키·응답 저장 여부를 검사한다.
5. 전체 테스트·독립 리뷰 후 결과와 한계를 기록하고 `feature/candidate-model-routing`에 push한다.
