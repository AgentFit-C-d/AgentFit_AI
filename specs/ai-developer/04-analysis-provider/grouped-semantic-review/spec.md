# 원문 선택자 분석의 묶음별 의미 검토 설계

## 목표와 현재 근거

현재 원문 선택자 분석은 10개 필드와 전체 원문을 한 번의 의미 검토 요청에 넣는다. Campfire PRD에서 4,096·8,192·16,384 출력 토큰 상한 도달이 관측됐고, 600초 실험에서 완성된 한 응답도 형식 검증에 실패했다. 사용자는 현재 정확도 개선에서 시간 제약을 우선하지 않으며, 의미 검토를 세 묶음으로 나누는 선택형 실험을 승인했다.

목표는 각 필드가 검토됐다는 증거 없이 자동 완료되지 않도록 하면서 한 요청의 출력 범위를 줄이는 것이다. 실제 정답과 정답 밖 값 검증 없이 서비스 기본값으로 승격하지 않는다.

## 선택한 방식과 대안

1. **선택:** 필드 묶음 3개를 순차 검토한다. 각 요청은 전체 원문과 해당 묶음의 Profile 초안, 명시적인 검토 필드 목록을 받는다. 응답은 `checkedFields`와 짧은 오류 목록이다. 세 응답을 서버가 검증·합친 뒤 모든 필드 검토가 완료되고 오류가 없을 때만 자동 완료한다.
2. 전체 검토의 출력 상한·기한만 늘리기: 600초에서도 형식 오류 또는 16,384토큰 상한으로 실패했다.
3. 원문을 구역으로 나누기: 구역 밖의 확정 사실을 놓칠 수 있어 별도 검색·범위 커버리지 계약이 먼저 필요하다.

## 내부 계약

- `grouped_review=False`가 기본이다. opt-in일 때만 원문 선택자 분석기의 의미 검토를 다음 고정 묶음으로 바꾼다: A `project_name, project_type, domain, frontend, backend`; B `ai, database, deployment, external_integrations`; C `features`. 순서는 A→B→C다.
- 각 호출의 schema는 자기 묶음 필드만 `checkedFields`에 정확히 한 번 포함하도록 요구한다. `issues`의 `field` 역시 해당 묶음으로 제한하고, 기존 배열 항목은 서버가 부여한 ID로 지정한다. 누락 이슈에는 원문 줄 ID가 필수다. 서버는 ID·필드·근거 줄·중복·형식을 공통 검증한다.
- 각 묶음 검토의 출력 상한은 4,096토큰이고 의미 검토 추론 설정은 `medium`이다. 평가 plan에는 전체 기한과 실제 묶음별 출력 상한을 기록한다.
- 모든 호출이 정상 완료되고 세 묶음의 합집합이 공개 Profile 10개 필드와 정확히 같아야 검토 완료로 인정한다. 한 호출이라도 미완료·검증 실패·호출 제한·기한 초과면 `needs_confirmation` 또는 기존 안전 실패로 보류한다. 앞서 성공한 묶음만으로 자동 확정하지 않는다.
- 한 묶음이라도 의미 이슈가 있으면 세 묶음의 유효 응답을 모두 모아 해당 필드를 확인 필요로 표시하고 자동 완료하지 않는다. 이 opt-in에서는 의미 수정·재검토를 시도하지 않는다. 오류를 가진 초안은 사용자 확인 없이 저장 가능한 Profile로 반환하지 않는다.
- 최초 core·features 2호출, 구조 근거 수정 최대 1호출, 의미 검토 3호출로 총 최대 6호출이다. 공개 Profile·기본 분석기·FastAPI 모드·키·진단 보관 정책은 바꾸지 않는다. 장시간 평가 옵션은 별개로 유지한다.
- 진단은 묶음 ID, 단계, 검증된 오류 종류/고정 사유, 숫자형 토큰·시간만 허용한다. 원문·원본 모델 응답·키·Profile은 공개 평가 결과에 저장하지 않는다.

## 검증과 승격 기준

- 단위/모의 테스트: 세 묶음 모두 정상일 때만 완료, 오류 하나가 있으면 확인 필요, 누락·중복·다른 묶음 필드·잘못된 ID·근거 줄·출력 상한·마지막 호출 실패는 자동 완료 금지. 기본 단일 검토와 최대 6호출 불변도 확인한다.
- 이미 튜닝한 Campfire 1건에서 출력 완성·검증 상태·부분 정답·정답 밖 값·호출 수를 측정한다. 유효한 결과일 때만 고정 튜닝 PRD 5건으로 확대한다. 응답 시간이 길어도 정확도와 오확정을 먼저 본다.
- 공개 문서는 이미 튜닝에 사용됐고 부분 정답만 있다. 독립 실제 문서의 사람 검토 및 Spring/Frontend 확인 전 저장 금지 E2E 없이는 실사용 가능 판정을 하지 않는다.
