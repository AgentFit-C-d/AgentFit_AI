# 구현 및 첫 파일럿 검증

## 구현
- 원문 블록 보존 옵션: 제목/문단/표/코드 블록을 기존 파서 기준으로 유지하고 고유 U ID 발급. 기존 분할 기본 동작은 유지.
- 후보 생성은 unitId/quote만 반환한다. 서버가 정확 위치를 검증하며 중복·누락·다른 단위 인용 거절.
- 별도 Solar 판단은 후보 ID별 필드·역할·상태·범위·선택 여부를 결정한다. 무관 후보는 필드를 강제하지 않는 irrelevant로 제외.
- 공개 Profile 및 기본 분석기를 유지한다. opt-in AnchoredAnalyzer.
- 최대6회·60초 협력 예산과 기존 실패 원본7일 정책 상속. 하드 네트워크 중단 보장은 기존과 동일하게 없음.
- 테스트246건 통과. 독립 검토 P2 누락 방어1건 재현 후 수정: 후보 외부 누락 또는 수정 후 같은 값·근거이면 실패.

## 첫 실제 파일럿
Mini4, 합성6사례, 모델 출력 전에 최종 의미 골드/허용표현/프롬프트 해시를 저장했다.
이 골드는 튜닝용 개발자 초안이다. 기존 후보 exact revision2 점수와 직접 비교하지 않는다.
- 의미 통과1/6: Q-005 (회의 정보 제외).
- PROVIDER_TIMEOUT4건: Q-001 재검토, Q-002 검토, Q-004 재검토, Q-006 재검토.
- SECTION_MERGE1건: Q-003 판단 검증 실패.
- Q-006만 후보 생성2회, 나머지 후보 생성1회.
- 첫6사례 통과 기준에 미달하여 추가2회 반복 및 실제문서 확대는 실행하지 않았다.
- 성공 결과/raw/reasoning 원문은 저장하지 않았다.

실험은 누락 방어 수정 전에 실행됐다. 수정 후 코드는 합성 회귀 테스트로 검증했고 실제 API 재평가는 아직 하지 않았다.
추가 검증 없이 이 결과를 최종 수정본 성능이라고 주장하지 않는다.

## 한계와 다음 작업
관찰된 시간 초과는 검토·재검토에서 발생했지만, 앞 단계가 예산을 얼마나 소모했는지 집계가 더 필요하다.
고정6회 상한과60초 예산을 늘려 성공으로 바꾸지 않는다.
단계별 시간/토큰을 안전한 metadata로 보존하고, 새 최종 의미 골드와 기존 의미 검토 기준의 충돌 여부를 확인한다.
골드는 모델 응답을 보고 수정하지 않는다. 의미 검토 최적화가 필요하면 동일 과제에서 전후 비교한다.
목표는 여전히 실사용 가능한 초안이며 미달이다. 공개 검증 문서는 미사용.
