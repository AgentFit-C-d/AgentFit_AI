# 튜닝 실험 종료 정리

## 결론
**이번 튜닝 회차를 종료합니다. 자동으로 확정된 Profile을 반환할 품질은 확보하지 못했습니다.**
구조 검증과 의미 정확도를 구분했고, 모델 변경·구역 분석·정확 인용·Jev 분류 분리까지 실험했습니다. 작은 평가의 부분 성공이 전체 문서 성공을 뜻하지는 않습니다.

## 주요 근거
- 동일7사례 Mini4 평가: 정답0/7.
- Mini4+Jev 통합: 정답1/7. 실패6건 중5건은추출,1건은최종검토. 추출도변동해Jev단독효과미확정. 실제문서2개모두실패.
- 단일 인용: 짧은6개구조통과6/6이나 의미정답0/6. 정확 인용을 얻고도역할분류오류가남음.
- 독립 역할·상태: 같은후보에두질문, 동시정답18/24, 잘못제품확정3회.
- 마지막동일사례비교: 기존2축19/24, 신규4질문16/24. 신규오채택0이지만 정상채택4회도모두미정으로남음.

각 실험은 과제와 데이터가 달라 서로의 정확도를 단순히 개선 추세로 비교할 수 없습니다. 마지막2축/4질문은 동일사례의 공통결정단위로 비교했습니다.
[마지막 비교](factual-questions/validation.md) · [통합 평가](jev-integration/validation.md) · [단일 인용](quote-extraction/validation.md) · [독립 분류](independent-classification/validation.md)

## 확보한 구현
- 원문과 정확히 일치하는 근거 위치 검증, 모호한 인용 거절.
- 구조·필드·역할·중복·충돌 검증, 안전한 실패 진단.
- Pro4/Mini4 비교와 Jev opt-in 실험 경로.
- 실제 요청 기준 호출/시간/단계별 실패 기록 및 합성 평가 도구.

위 구현 검증이 내용의 정확성을 보증하지는 않습니다.

## 서비스 사용 범위에 대한 판단
현재 결과로 AI 결과를 검증된 최종 Profile로 자동 확정하는 방식은 권장하지 않습니다.
향후 제품 흐름을 정할 때 원문 근거를 동반한 초안과 중요한 불확실성의 사용자 확인을 검토할 수 있습니다. 이는 아직 구현·승인된 새 API 계약이 아닙니다.
사용자 확인을 넣더라도 누락과 잘못된 근거 검증은 계속 필요합니다.

## 남은 제약
실제 문서 holdout 부족, 소규모 단일 반복, 개발자 작성 임시 정답, 선택지 순서 민감성, 명시적 부정/예시/미정 구분 실패.
60초 예산은 협력적 검사이며 하드 중단은 보장하지 않습니다.
기본 분석기를 새 실험으로 교체하거나 배포하지 않았습니다. 모델의 일반 능력 전체가 부족하다고 단정하지 않습니다.

## 후속 작업 경계
추가 프롬프트 튜닝은 이번 회차에서 진행하지 않습니다.
사용자 확인 UI/API 계약은 사용자가 보류한 상태이며 자동으로 시작하지 않습니다.
