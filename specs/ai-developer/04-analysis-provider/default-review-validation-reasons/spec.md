# 기본 의미 검토 오류 사유 진단

## 목적

기본 Solar 분석은 `SEMANTIC_REVIEW_INVALID`를 반환하지만 모델 검토 응답이 어떤 고정 규칙을 위반했는지 내부 평가에서 볼 수 없다. 공개 오류는 유지하며 원문 없는 안전 진단으로 원인을 구분한다.

## 계약

- `ReviewValidationError.reason`이 `REVIEW_INVALID_REASONS`에 있을 때만 현재 검토 호출의 내부 진단에 기록한다. 그 외 문자열은 기록하지 않는다.
- 기본 분석기 평가 산출물에는 허용된 사유 코드만 전달하고, 사유별 건수를 집계한다. 원문·Profile·인용·모델 응답·임의 예외 문자열은 저장하지 않는다.
- 정상 검토, Provider 실패, 근거 검증 실패의 결과는 기존과 같아야 한다. `SEMANTIC_REVIEW_INVALID` 공개 코드와 재시도/호출 제한도 바꾸지 않는다.
- 합성 사례에서 형식 오류가 다시 발생하면 사유 코드를 확인한다. 미재현이면 추정하지 않고 미재현으로 기록한다.

## 완료 기준

- 허용된 사유의 기본 분석기→평가 산출물 전달, 임의 사유 차단을 테스트한다.
- 전체 회귀 테스트 통과와 제한된 실제 모델 재평가 결과를 남긴다.
- feature 브랜치에 커밋·push한다.
