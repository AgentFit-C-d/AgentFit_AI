# Anchored 검토 시간 비교
승인된 anchored 실험의 후속 진단이다. 공개 Profile과 기본 분석기는 유지한다.
- 검토/재검토에만 opt-in reasoning_effort를 적용한다. 기본 medium, 비교 low.
- 추출/판단 none, 검토 max_tokens 8192, 최대 6회/60초, 프롬프트와 정답은 동일하다.
- 성공과 실패 모두 단계별 시간·토큰·오류 코드만 기록한다. 원문/응답/추론 텍스트는 저장하지 않는다.
- 고정 합성 6건을 설정별 1회 비교한다. 전부 통과해야 반복/확대한다.
- 시간 감소와 의미 정확도를 따로 보고한다. 실서비스 사용 가능 판정은 별도다.
