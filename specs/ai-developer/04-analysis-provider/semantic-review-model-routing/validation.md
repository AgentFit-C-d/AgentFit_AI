# 의미 검토 모델 분리 검증

## 변경

- `AnchoredAnalyzer(review_model=..., review_api_key=...)`를 선택형으로 추가했다. 미지정 기본값은 기존 Solar 모델만 사용한다.
- 후보 추출·판단·수정은 Solar Pro4를 유지하고, 의미 검토·재검토만 지정한 NVIDIA 모델로 보낸다. 표준·compact 검토 계약 모두 지원한다. 공개 Profile과 최대 6회·60초는 그대로다.
- 지원 후보는 `deepseek-ai/deepseek-v4.1-flash`, `z-ai/glm-5.3`, `moonshotai/kimi-k3`다. 실제 반환 모델명을 검증하고 안전 진단에 허용된 모델명만 남긴다.
- NVIDIA 키가 문서나 문서 ID에 포함되면 첫 Solar 호출 전에 거부한다.

## 합성 호환성 검사

`results/pilot1`은 정답에 무관한 짧은 합성 문장과 compact JSON Schema를 사용했다. 호출별 상한은 40초다.

| 검토 모델 | 결과 | 경과 |
|---|---|---:|
| DeepSeek V4.1 Flash | 유효한 빈 이슈 응답 | 18,406ms |
| GLM 5.3 | 제공자 시간 초과 | 40,094ms |
| Kimi K3 | 제공자 시간 초과 | 40,110ms |

GLM과 Kimi의 한 번의 시간 초과는 모델이 이 계약을 지원하지 않는다는 증거가 아니다. 이번 서비스 시간 제한의 20건 비교에서는 제외했다.

## 20건 교차 평가 1차

`results/run1`에서 동일 합성 20건을 Solar Pro4 검토(`baseline`)와 DeepSeek 검토(`compact`)로 번갈아 실행했다. 두 방식 모두 Solar Pro4 후보·판단, compact 검토 계약, 전체 60초·검토 호출별 40초 상한을 사용했다.

| 지표 | Solar 검토 | DeepSeek 검토 |
|---|---:|---:|
| 전체 Profile 완전 일치 | 5/12 | 7/12 |
| 다구역 지정 사실 성공 | 0/8 | 1/8 |
| 전체 성공 | 5/20 | 8/20 |
| 검토·재검토 시간 초과 호출 | 4 | 0 |
| 검토 형식 오류 호출 | 1 | 0 |
| 의미 검토 거절로 끝난 사례 | 3 | 9 |
| 오확정 | 0 | 0 |
| 검토 제공자 처리 중앙 시간 | 11,586ms | 11,109ms |

두 방식 모두 호출 수는 최대 6회였다. DeepSeek 방식의 최대 관측 시간은 59,703ms였다. Solar 방식의 E01·E06은 60,062ms로 설정값을 62ms 초과해 자동 관문 `observed_60s_limit`이 실패했다. 다른 정확도·형식 오류 관문은 통과했지만, 의미 검토 거절 9건과 앞단 호출의 변동을 고려해 기본값을 변경하지 않는다.

각 방식은 후보·판단도 독립적으로 다시 호출했다. 따라서 성공 5→8건을 검토 모델만의 인과 효과로 해석할 수 없다. 두 방식이 모두 반환한 전체 Profile 5건은 모두 10/10이었다. 이 자료는 튜닝에 사용됐으며 신규 실제 문서 검증도 없다. 다음 단계는 동일한 후보·판단 응답을 메모리에서 공유하는 검토 단계 한정 비교와 별도 실제 문서 검증이다.

## 현재 코드 재평가

NVIDIA 키 사전 차단을 추가한 뒤 `results/run2`에서 같은 20건을 다시 교차 실행했다. 현재 코드 해시는 run2 계획에 기록됐다.

| 지표 | Solar 검토 | DeepSeek 검토 |
|---|---:|---:|
| 전체 Profile 완전 일치 | 5/12 | 6/12 |
| 다구역 지정 사실 성공 | 1/8 | 1/8 |
| 다구역 지정 사실 일치 수 | 6/27 | 3/27 |
| 전체 성공 | 6/20 | 7/20 |
| 검토·재검토 시간 초과 호출 | 4 | 1 |
| 검토 형식 오류 호출 | 2 | 1 |
| 의미 검토 거절로 끝난 사례 | 0 | 6 |
| 오확정 | 3 | 0 |
| 검증 계열 오류 | 7 | 11 |

DeepSeek의 Q-002 검토는 시간 초과됐고 E05는 `COMPACT_MISSING_SOURCE_EMPTY` 형식 오류였다. DeepSeek 최대 관측 시간은 49,844ms다. Solar E02·E05는 각각 60,047ms·60,032ms로 설정값을 약간 초과했다. 2차 자동 관문은 **다구역 정확도 감소, 검증 오류 증가, 관측 60초 초과**로 실패했다.

두 번의 실행에서 성공 건수는 DeepSeek가 각각 3건·1건 많았지만, DeepSeek 의미 검토 거절은 9건·6건이었고 2차에서는 다구역 지정 사실 회수가 낮았다. **기본 검토 모델로 승격하지 않는다.** 모델 라우팅은 선택형 실험으로만 유지한다. 같은 후보·판단 응답을 공유하는 비교와 신규 실제 문서 검증 전에는 검토 모델 자체의 인과 효과나 실사용 가능성을 주장할 수 없다.
