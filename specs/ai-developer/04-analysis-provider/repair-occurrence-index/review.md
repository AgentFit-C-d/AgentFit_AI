# 독립 검토
구현 검토: 검증기·스키마·기본 False·원래 구역·전역 오프셋에서 신규 결함을 발견하지 못했다.
평가 P2: 기존13건은 위치 정답이 없어 S02의 개발용 첫 등장을 골라도 값만 같으면 통과할 수 있었다. 기존 결과는 값 정답 평가로 표시하고 state-evidence.json을 별도로 사전 고정한 후 새로운 실행으로 재검증했다.
부재 O08 판정: start24/end50는 “현재 제품 정책: 운영 AI를 사용하지 않는다.”이고 gold34/end50는 같은 문장의 서술 부분이다. 원래 계약이 현재 범주 전체 부재 문장을 허용하므로 실제 출력도 유효하다. 문서 전체처럼 예시·다른 제품을 섞은 과도한 인용까지 허용해서는 안 된다. 기존 strict span 점수는 유지하고 별도 판정만 기록한다. 이는 반복된 짧은 인용의 두 번째 등장 계산 성공을 입증하지 않는다.
검토자는 API·테스트를 실행하지 않았다. 작성자는299건 테스트를 통과했다.
