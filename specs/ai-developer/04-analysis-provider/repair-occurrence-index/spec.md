# 수정 인용 등장 순서 계약 — 사용자 승인 완료
## 목적과 근거
Pro4/none 상태13건 중12건은 통과했지만 반복 이름 S02는 SOURCE_REPAIR_INVALID였다. 문장 분리 방식은 Dr. Atlas처럼 경계를 가로지르는 이름을 손상시켰다. 원래 구역을 유지하며 반복 인용의 특정 등장을 지정할 수 있게 한다.
## 변경
수정 단계의 opt-in 응답 facts에서 context를 occurrenceIndex로 대체한다. quote/unitId/role/status/scope는 유지한다. occurrenceIndex는 원래 unit 안에서 정확한 quote가 나타나는 순서(1부터 시작)다. 서버가 왼쪽부터 비중첩 정확 일치 목록을 만들어 지정한 위치의 전역 span을 계산한다. 모델이 문자 오프셋을 계산하지 않는다. 인덱스는 정수1~24000이고 실제 등장 수 범위 밖이면 실패한다. bool/실수/0/누락/여분 필드는 거부한다.
단일 등장도1을 지정한다. 부재 근거도 같은 규칙을 따른다. quote를 다른 문장·구역과 합성하지 않는다. 초기 후보/판정/전체 검토/공개 Profile/모호한 근거 거부는 유지한다. 기존 context 계약은 기본 경로로 남기고 새 옵션 기본값False다. 원래 구역을 사용하며 sentence split과 동시 활성화는 거부한다.
## 위험과 검증
모델의 순서 계산 오류로 개발용 인용을 운영 근거로 지정할 수 있다. 따라서 데이터 값 일치만으로 성공 처리하지 않고 예상 start/end까지 검사한다. 같은 이름2회·3회·문장 안 반복·개발/운영 순서 반전·과거/현재·약어·CRLF·한글·이모지·부재를 사전 고정한다. 잘못된 발생 위치를 조용히 첫 번째로 바꾸는 fallback은 금지한다.
## 불변 조건
서버가 임의로 의미를 판정하거나 중복을 숨기지 않는다. 전체6회60초 및 부분 실패 정책을 유지한다. 호출 단계 추가 없음. 기본 모델 승격 없음. 공개 API와 Profile 변경 없음.
## 대안 비교
context 유지: 변경이 없으나 반복 인용 실패가 남음.
문장 분리: 인용을 유일하게 만들지만 약어/경계 이름에 실패.
등장 순서: 구역 보존, 추가 호출 없이 특정 인용 지정. 순서 오판 위험은 별도 근거 위치 정답으로 검증해야 함.
