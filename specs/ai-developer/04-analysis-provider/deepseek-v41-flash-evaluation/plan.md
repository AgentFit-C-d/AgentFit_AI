# DeepSeek V4.1 Flash 비교 계획

1. 평가 어댑터 테스트를 먼저 작성한다. 요청에서 모델·비추론 옵션만 NVIDIA용으로 바뀌고, 후보·프롬프트·스키마·정답 비전송·안전한 응답 처리를 확인한다.
2. NVIDIA 전송 함수와 기존 원자 판정 채점 재사용 CLI를 구현한다. 데이터 해시를 확인하고 출력 디렉터리를 새로 만들며, 매 호출 후 안전한 결과를 기록한다.
3. 관련 테스트와 전체 회귀 테스트를 실행한다.
4. 합성 33건을 실행한다. 시간 초과·일시 오류는 같은 실행의 결과로 기록하고, 원인 없이 재시작해 유리한 결과로 대체하지 않는다.
5. 기존 Solar atomic 점수와 동일 지표로 비교해 `validation.md`에 오류·한계·다음 결정을 남긴다. 평가 코드를 검토하고 이 브랜치를 commit/push한다.

## 변경 파일
- `ai_service/agentfit_ai/deepseek_evaluation.py`: 전송·응답 파서 연결·고정 평가 CLI.
- `ai_service/tests/test_deepseek_evaluation.py`: 계약/안전성 회귀 테스트.
- 이 디렉터리: 명세·계획·결과·검증 기록.
