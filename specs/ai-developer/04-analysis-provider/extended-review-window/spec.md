# 평가 전용 긴 의미 검토 기한

## 목적과 근거

Solar Pro4의 Campfire PRD 의미 검토는 8,192 출력 토큰을 채운 채 끝나지 않았고, 16,384토큰 설정은 전체 300초 기한에 도달했다. 사용자는 현재 실험에서 응답 시간을 품질 결정의 우선 제약에서 제외했다. 같은 검토 계약을 더 긴 기한에서 완성하는지 확인한다.

## 계약

- 공개 PRD 평가 CLI의 `--source-selector --accuracy-first --extended-review-window`에서만 전체 분석 기한을 600초로 둔다. 필드 호출 120초, 의미 검토 상한 16,384토큰, 모델·원문 선택자·의미 검토 schema·최대 6호출은 유지한다.
- `--extended-review-window`는 간결 검토와 함께 사용하지 않는다. 기본 서비스·공개 Profile·저장 정책·FastAPI 기한은 바꾸지 않는다.
- 결과 plan은 실제 600초와 출력 상한을 기록한다. 실제 호출이 완료되더라도 부분 정답·정답 밖 값·오확정 검증 없이는 기본값으로 채택하지 않는다.
- 의미 검토 응답이 완성됐지만 서버 형식 검증에 실패하면, 평가 결과에는 허용된 고정 사유 코드만 기록한다. 원본 응답·문서·키는 기록하지 않는다.

## 검증

- CLI 조합·실제 기한·기본 경로 불변을 모의 테스트하고 전체 테스트를 실행한다.
- 이미 튜닝에 쓴 Campfire PRD를 600초로 실행한다. 검토 완성·상한 도달·검증 실패 코드·부분 정답과 미평가 값을 안전한 숫자로 기록한다.
- 실패하면 기한만 늘리는 방식을 종료하고 검토 범위 분할을 별도 설계한다. 성공하면 5건으로 확대하되 독립 서비스 품질 근거로 간주하지 않는다.
