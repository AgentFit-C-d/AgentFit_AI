# 구현 계획

1. 기존 판단 프롬프트의 필드·역할 규칙을 보존하면서 후보별 `facts[]` 하위 인용 응답 스키마를 만든다.
2. 서버의 하위 인용 검증·절대 위치 계산·기존 Profile 병합 연결을 순수 함수로 구현한다. 가짜 응답 테스트를 먼저 실패시킨다.
3. `AnchoredAnalyzer`에 기본 꺼짐 옵션을 추가하고 최초 판단·의미 수정에 같은 계약을 적용한다.
4. 합성 평가 CLI에 선택형 옵션을 연결하고, 단계 진단의 잘못된 `candidate_gap` 추정을 막는다. `Q-001`, `N-004`, `N-006`을 먼저 실행해 유효성을 판단한다.
5. 유효하면 20건으로 확대하고 결과 보안·전체 테스트·독립 리뷰·feature 브랜치 push를 수행한다.
