# 필드별 의미 검토 검증 기록

## 로컬 구현 검증

- `fieldwise_review=True`는 기존 구역 추출·대표 기능 선택 실험에서만 허용한다. 기본값은 `False`다.
- 검토 순서는 기존 A 묶음 다음 `ai`, `database`, `deployment`, `external_integrations` 각 단일 필드, 마지막 `features` 구역 검토다. 서버는 10개 필드 전체 커버리지를 확인한다.
- 7개 기능 구역·대표 기능 선택·근거 수정·필드별 검토의 최대 경로가 22호출 안에서 완료되는 모의 테스트를 통과했다. 마지막 필드·구역 검토가 잘못되면 자동 완료하지 않는다.
- Windows 로컬 전체 `unittest discover -s tests -q`: 690건 통과 (2026-09-29).

## 실제 튜닝 문서 평가

Campfire PRD 1건에 대한 Solar Pro 4 평가 실행 중. 결과 확인 후 완료 상태·부분 정답·미평가 값·호출 수와 기존 19회 모드 비교를 여기에 기록한다.

## 적용 판단

실제 평가, Linux CI, 독립 코드 리뷰가 끝나기 전에는 실서비스 기본값으로 승격하지 않는다. 공개 튜닝 문서의 부분 정답만으로 일반 정확도는 입증할 수 없다.
