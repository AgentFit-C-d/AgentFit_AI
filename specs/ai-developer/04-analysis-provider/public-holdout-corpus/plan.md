# 구현 계획

1. 고정 소스와 사람이 확인한 일부 필드·근거 문구를 manifest에 기록한다. 원문은 포함하지 않는다.
2. 제한된 공개 URL만 받아 크기·UTF-8·SHA-256을 검사하는 로더를 구현한다.
3. 모델 호출 전에 manifest의 필드·인용·중복을 검사한다. 채점은 값과 근거를 별도로 세고 미채점 필드를 남긴다.
4. 현재 복구형 Solar 경로를 한 번씩 호출하는 평가 CLI와 안전한 결과 요약을 추가한다. 실행 결과는 로컬 ignored `tmp/`에만 기록한다.
5. 오프라인 테스트 후 공개 문서 3건을 실제 평가한다. 실패와 60초 초과도 그대로 보고한다. 이 결과를 튜닝에 사용하면 해당 세트의 독립성은 소멸한 것으로 표시한다.

기본 FastAPI 분석기·공개 Profile 계약·Spring 계약은 변경하지 않는다.
