# 공개 독립 문서 평가 세트

## 목적

튜닝에 쓰인 AgentFit·MABC·Handoff·합성 문서와 다른 실제 제품 문서로 분석 품질을 측정한다. 문서 내용이나 모델 Profile은 Git과 평가 결과 파일에 저장하지 않는다.

## 범위

- 공개 저장소의 고정 커밋에 있는 Markdown 문서 3건(Actual Budget 제품 문서, Mealie·Immich README)을 초기 세트로 사용한다.
- 원문은 실행 중에만 내려받고 URL·커밋·SHA-256·크기 상한을 검증한다. 원문이 바뀌거나 받지 못하면 해당 평가를 실패 처리한다.
- 모델 출력 중 사람이 문서에서 분명히 확인한 일부 필드와 근거 구간만 채점한다. 나머지 제안은 `unassessed`로 남긴다. 문서의 부재만으로 미정의 정답을 만들지 않는다.
- 평가 결과에는 사례별 상태·지연·호출 수·채점 수와 오류 수만 기록한다. 원문·인용·API 키·Profile은 기록하지 않는다.
- 이 세트는 영어 공개 제품 문서 3건이며 사용자 기획서의 전체 분포, 한국어 문서, 독립 사람 검토 5~10건을 대표하지 않는다. 실사용 최종 게이트는 이 세트만으로 통과할 수 없다.

## 수용 기준

1. 세 문서가 고정된 커밋과 SHA-256으로 재현된다. 해시·크기·URL·인코딩 오류는 모델 호출 전에 중단된다.
2. 수동 정답은 원문 내 정확한 짧은 인용을 갖고, 확실한 필드만 표기된다.
3. 성공·확인 필요·실패를 모두 사례 수에 포함하고, 미채점 제안을 오답 0으로 취급하지 않는다.
4. API 호출 없는 단위 테스트에서 변조 원문과 부정확한 정답을 거부한다.
