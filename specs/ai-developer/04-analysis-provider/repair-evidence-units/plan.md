# 구현 계획 — 사용자 승인 완료
1. 기존 구역에서 손실 없이 하위 span을 만드는 순수 함수와 회귀 테스트 작성.
2. 실제 quote 위치/중복/CRLF/URL/소수점/약어/다중 문장/400개 제한 검증.
3. source_repair opt-in 경로의 요청 units와 apply_repairs mapping만 같은 하위 단위로 교체. 초기 추출과 공개 응답은 보존.
4. 승인 시 고정한 상태 판단 프롬프트로 현재13건3회와 별도 새 문맥/부재/양성 대조 세트를 비교. 같은 간격과 호출/시간 상한 사용.
5. 기존 전체12건3회, 근거검증100%, 추가 잘못된확정0, 실패 포함 품질·지연 기록. 전부 양호해도 독립 문서와 사람 수정 부담 검증 없이는 실사용 완료 처리하지 않음.
6. 실패는 근거를 보존하고 기본값 승격 없이 결과를 보고.
