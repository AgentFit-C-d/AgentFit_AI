# 분석 초안 실사용 평가 v1

## 목표와 범위
사용자가 적은 수정으로 확정할 수 있는 근거 있는 Profile 초안. UI/API 개편과 배포는 별도이다.
이 문서는 초기 파일럿 판정 기준이다. 결과를 확인한 뒤 문턱을 낮춰 통과시키지 않는다. 변경 시 새 버전과 이유를 남긴다.

## 정답 작성
문서별 10개 필드에 원문 근거, 의미 단위, 허용 표현, 확정/미정/명시적 부재를 사람이 검토한다.
기능은 행위자·행동·대상을 보존한다. '승인 요청'과 '승인 처리'는 별개다. 형식만 다른 동의 표현은 사전 등록해 허용한다.
값을 정규화해도 근거는 원문과 정확히 일치해야 한다. 원문 없는 기술·도메인 추론은 불가.
개발 전용·예시·회의 정보는 제품 요구사항이 아니다. 미정과 명시적 부재를 구분한다.
명시적 부재는 해당 필드의 별도 의미 단위로 채점한다. unknown은 정답 수를 부풀리는 단위로 세지 않는다.
일대일 의미 대응으로 TP/FP/FN을 집계한다. 중복 출력은 FP. 잘못 바꾼 항목은 FP와 FN 각각 1이다.
골드는 모델 응답을 보기 전에 작성·검토하고 해시로 고정한다. 모호한 항목은 보류 목록에 기록하며 임의로 정답화하지 않는다.

## 데이터 분리
- AgentFit/MABC/Handoff와 현재 모든 노출 fixture는 튜닝용이다.
- 최종 검증: 서로 다른 실제 기획서 10개 이상, 문서별 3회, 새 문서. 반복은 표본 수를 30개로 늘린 것으로 표현하지 않는다.
- 내용 중복/개정판은 같은 문서 계열로 묶어 분할한다. 해시 중복도 금지한다.
- 새 문서가 없으면 최종 검증 미완료다. 합성 사례로 대체하지 않는다.
- 검증 문서를 보고 수정하면 해당 자료는 튜닝용으로 이동한다. 새 검증 세트가 필요하다.

## 파일럿 기준 (모두 만족)
- 전체 및 평가된 각 필드 precision >=95%, recall >=90%. 10개 필드 각각 양성 정답을 포함해 평가한다.
- 요청 실패율 <=5%. 실패 요청도 FN=전체 골드로 포함한다.
- 반환된 모든 의미 단위의 근거 검증 100%.
- 명시적 부정/미정/다른 제품의 사실을 현재 확정으로 바꾸는 중대 오류 0회.
- 문서별 3회 각각 precision/recall 기준 만족. 쉬운 문서/성공 호출 평균으로 실패를 숨기지 않는다.
- 수정 부담: 각 문서의 첫 실행에 대해 사람이 추가+삭제+수정 횟수를 기록. 골드 단위 수 대비 수정률 평균 <=10%, 수정 시간 중앙값 <=120초, p95 <=300초.
- 요청 시작부터 최종 성공/실패까지(재시도 포함) 응답 시간 p95 <=60초.
- 원문 노출 없이 검토자 기록과 고정된 corpus/gold/config ID를 보존한다.

## 주의
집계 도구는 사람이 검토한 계수의 일관성과 문턱을 검사한다. 입력한 정답·출처·수정 시간의 진실성을 인증하지 않는다.
95%/90%는 제한된 파일럿 점추정 목표이며 전체 고객에 대한 통계적 보장은 아니다.
입력/측정 누락, 미평가 필드, 작은 세트는 pass가 아닌 미완료다.
