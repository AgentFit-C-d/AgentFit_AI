# 검증 및 사용

## 완료한 범위
- 실사용 초안 평가 v1 명세와 원문 없는 수치 집계기.
- 단위 테스트는 집계 로직만 검증한다. 모델 품질이나 실제 사용자 수정을 검증하지 않는다.
- 평가 입력은 문서별 run 0/1/2, 10개 필드 TP/FP/FN/근거 유효 개수, 지연·중대 오류·첫 실행의 수정량/시간이다.
- 동일 문서의 반복 실행에서 골드 개수가 바뀌면 입력 오류다.
- 숫자 집계가 통과해도 문서 신규성, 계열 중복, 골드/설정 고정, 검토 기록을 사람이 별도 감사해야 한다.
- 현재 명세는 각 실행 품질 기준도 요구하므로 요청 실패 1건도 각 실행 기준을 통과하지 못한다. 실패율 5% 기준은 별도 진단 지표이며 실패 허용권이 아니다.

## 실행
`python -m agentfit_ai.draft_readiness reviewed-counts.json`
반환 scope는 numeric_only_requires_dataset_and_human_audit이다. 원문 및 비밀 값이 포함된 입력을 만들지 않는다.

사용자는 신규 문서 제공이 불가능하다고 답했다. 공개 실제 프로젝트 자료로 별도 검증 세트를 확보하되 대표성 차이를 표시한다. 사용자 수정량/시간은 별도 측정해야 한다.
사용자 수정 시간/수정량은 아직 측정하지 않았다. 이전 0/6 등의 결과는 새 의미 단위 기준의 점수로 전환하지 않았다.
