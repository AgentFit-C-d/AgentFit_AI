# 기능 검토 구역 세분화 검증 기록

## 로컬 검증

- 선택형 `fine_feature_review=True`에서 기능 추출은 기존 120줄 구역을 사용하고 기능 의미 검토는 50줄 구역을 사용한다. 전체 줄 커버리지와 최대 21개 구역을 검증한다.
- 모의 평가에서 마지막 검토 구역의 범위 오류는 자동 완료하지 않으며, 22개 구역은 제공자 호출 전에 거부한다.
- 새 옵션에서만 최대 36호출·2,400초를 허용한다. 옵션이 꺼지면 기존 22호출·1,200초 상한을 유지한다.
- Windows 로컬 전체 `unittest discover -s tests -q`: 695건 통과 (2026-09-29).

## 실제 평가

Campfire PRD 1건을 Solar Pro 4로 평가한 뒤 안전 집계와 검토 완주 여부를 기록한다. 원문·키·원본 응답·Profile 내용은 저장하지 않는다.

## 적용 판단

실제 평가와 Linux CI·독립 리뷰 전에는 선택형 실험으로만 유지한다. 튜닝에 사용한 공개 문서의 부분 정답만으로 실사용 가능성을 주장하지 않는다.
