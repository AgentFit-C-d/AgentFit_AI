# 실행 계획

1. `SolarAnalyzer`의 전체 제한을 기본 60초인 선택형 생성자 설정으로 만든다. 기존 호출자는 모두 같은 60초 경로를 사용한다.
2. 평가기 전용 하위 분석기에서 의미 검토 호출을 40초로 제한해 두 조건의 개별 호출 상한을 동일하게 한다. 관련 옵션·데드라인·호출 횟수 테스트를 먼저 작성한다.
3. 기존 20건 자료와 채점기를 재사용하는 교차 평가기를 작성한다. 60초와 120초 순서를 사례마다 바꾸고 실행 전 설정·해시·판정 기준을 기록한다.
4. 안전한 사례별 결과와 고정 분모·공통 성공 쌍·단계별 오류·지연을 집계한다. 채점과 오류 분류 단위 테스트를 실행한다.
5. 실제 API 비교, 결과 보안 점검, 전체 회귀 테스트와 독립 검토 후 `validation.md`를 작성한다. 기능 브랜치에 해당 파일만 커밋·push한다.
