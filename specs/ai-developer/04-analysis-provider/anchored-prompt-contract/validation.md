# 프롬프트 계약 실험
## 구현 검증
opt-in prompt_revision=v2, 기본v1 유지. 후보·판단·수정에 선택한 프롬프트가 적용된다.
내부 인용 계약/공개Profile/6회60초/기본 분석기는 유지했다. 단위 테스트252건 통과.
## 고정 초안 평가
원래6+새 합성6. 새 골드는 프롬프트 작성/API 호출 전에 고정했다.
검토 진입 시 Profile을 메모리에서 평가하고 종료하는 probe다. 원문 응답/성공Profile은 저장하지 않았다.
|조건|초안 골드 통과|
|---|---|
|Mini4 v1 schema|3/12|
|Mini4 v2 schema|4/12|
|Mini4 v2 후보만 json_object|4/12|
|Pro4 v2 schema|4/12|
v2 통과는 Q003·Q005·N001·N003으로 모두 해당 필드가 미언급/미정/비대상인 사례다.
중요한 양성 추출/명시적 부재 사례는 통과하지 못했다. 숫자상 +1건을 실질적인 실사용 개선으로 주장하지 않는다.
추가4건 진단(Q001/Q004/N004/N005)에서는 모두 빈 후보가 관측됐다. 처음v2 실행과 변동성이 있으며 이 결과를 전체12건의 동일 실행으로 합치지 않는다.
Pro4는 부재2사례에서 SECTION_MERGE, 나머지 오류는 골드 불일치였다.
초안12건 모두 통과 조건 미달로 전체 검토 포함 평가/추가반복/실제 문서 확대는 실행하지 않았다.
## 판단
프롬프트·응답형식·모델 변경으로 핵심 문제가 해소되지 않았다.
현재 수정 단계는 기존 후보 판단만 바꾸므로 빠진 값이나 분리된 동작을 만들 수 없다.
스킬의 반복 실패 재검토 기준과 기존 anchored spec의 미달 시 구조 재검토 규칙에 따라 추가 프롬프트 누적을 멈췄다.
다음 검토안은 anchored-source-repair/spec.md, plan.md에 작성했다. 아직 승인·구현·효과 검증되지 않았다.
최종 실사용 목표는 미달. 공개 검증 corpus와 사람의 수정 부담 측정은 수행하지 않았다.
