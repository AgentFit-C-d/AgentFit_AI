# 계획
1. 새 합성6사례와 최종 Profile 골드를 프롬프트 작성/호출 전에 고정한다.
2. opt-in v2 선택·호출 경계 테스트 후 최소 구현한다.
3. 기존6+새6에서 v1/v2 초안(검토 직전) 품질을 같은 고정 골드로 비교한다.
4. 초안12건 전부 맞는 경우에만 전체12건 검토 포함 평가로 확대한다.
5. 부족하면 원인/고정 결과를 보존하고 무작정 반복하지 않는다.
## 한계
합성 개발자 골드이며 고객 문서 최종 검증이 아니다. 초안 통과를 전체 pipeline 성공으로 표시하지 않는다.
