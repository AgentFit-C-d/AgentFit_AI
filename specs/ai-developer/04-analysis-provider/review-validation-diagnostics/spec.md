# 검토 응답 검증 진단
## 문제
12건 평가에서 2건이 SEMANTIC_REVIEW_INVALID로 실패했지만 구체적 규칙 위반을 구분할 수 없다.
## 요구
기존 허용/거부 판정 및 공개 오류 코드는 유지한다. 내부 예외에 고정된 사유 코드만 추가하고 실험 분석기의 호출 진단과 안전한 평가 결과에 전달한다. 원문, 모델의 임의 문자열, 잘못된 필드 값은 저장하지 않는다.
사유: 루트 구조, 전체 필드 확인 목록, 이슈 목록, 이슈 구조, 필드/종류 열거형, 근거 줄, missing 인덱스, null에 대한 잘못된 오류, 배열 인덱스, 스칼라/빈 배열 인덱스.
## 검증
각 거부 분기의 사유 회귀 테스트, 동일 오류 코드 유지, 정상 계약 수용, 분석기→평가 전달 및 비허용 진단 제거. 같은 모델/프롬프트 고정12건을 한 번 실행하여 현재 실패 원인을 기록한다. 이전 실패의 원인으로 소급 단정하지 않는다.
