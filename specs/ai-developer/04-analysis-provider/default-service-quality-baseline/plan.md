# 구현 계획

1. 기본 Worker 설정을 조사하고 평가 도구 테스트에서 같은 옵션 사용, 성공·실패 분리, 안전한 출력 계약을 먼저 고정한다.
2. 기존 20개 합성 사례 로더·채점기를 재사용하는 CLI 평가 도구를 구현한다. 평가 산출물은 생성 전 경로 존재 여부를 확인한다.
3. 단위 테스트 및 전체 테스트를 실행한다.
4. 로컬 API 키로 20건을 한 번 평가하고 결과·한계를 문서화한다. 시간 제한 및 호출 제한도 확인한다.
5. 기능 브랜치를 push한다. 결과를 보고 다음 개선을 별도 feature 브랜치에서 진행한다.
