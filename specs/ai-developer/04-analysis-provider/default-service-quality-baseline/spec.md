# 기본 서비스 분석 품질 기준선

## 목적

실제 `analysis_worker`가 사용하는 SolarAnalyzer 설정의 의미 정확도와 실패율을 기존 20개 합성 문서에서 측정한다. 선택형 분석기의 수치를 기본 서비스 성능으로 해석하지 않는다.

## 범위

- Worker와 동일한 모델, 근거 계약, 의미 검토, 40초 분석 제한, inline HTTP 전송으로 문서당 한 번 분석한다.
- 전체 정답 및 집중 정답을 기존 채점기로 평가하고, 완료·실패·오확정·정답 일치·지연·호출 수를 사례별 및 전체로 기록한다.
- 사례 원문, Profile, 모델 응답, API 키는 평가 산출물에 기록하지 않는다. 평가 데이터와 코드 해시, 설정, 평가 한계를 남긴다.
- 서비스 동작, 공개 Profile, 기본 분석기 설정을 변경하지 않는다.

## 완료 기준

- 합성 20건을 모두 한 번씩 평가하고, 실패를 정답으로 세지 않는다.
- 결과에 원문과 비밀 값이 없음을 검증한다.
- 기존 단위 테스트와 평가 도구 테스트를 통과한다.
- 이 측정은 독립 실문서 검증이나 서비스 전체 HTTP 경로 검증을 대신하지 않는다고 명시한다.
