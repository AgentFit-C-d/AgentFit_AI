# 구현 계획

1. 근거 오류의 허용 사유·필드·숫자만 복사하는 함수를 추가한다.
2. `SolarAnalyzer`의 최종 투영과 의미 수정 재투영 실패 진단에 함수를 적용한다.
3. 공개 평가 실행에서 원문 없는 단계/사유만 수집한다. 복구형 분석이 오류를 결과로 바꾸더라도 내부 진단을 읽을 수 있게 한다.
4. 가짜 Provider 회귀 테스트, 기존 공개 평가 테스트, 전체 테스트를 실행한다.
5. Mealie·Immich를 동일 설정으로 재실행하고 실패 원인과 미확정 사항을 기록한다. 결과를 보고 프롬프트나 검증 규칙을 즉시 변경하지 않는다.
