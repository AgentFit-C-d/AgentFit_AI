# 기본 서비스 호출 단계 시간 진단

## 문제와 목적

기본 Worker 설정의 합성 20건 평가에서 7건이 40초 Provider 시간 초과로 실패했다. 기존 결과는 어떤 호출 단계가 시간을 소모했는지 보여 주지 않는다. 같은 설정으로 재평가해 단계별 지연과 실패 위치를 확인한다.

## 동작

- 기존 `SolarAnalyzer`가 성공·실패 시 메모리에 남기는 진단만 평가 도구에 수집한다. 서비스 코드와 공개 응답은 변경하지 않는다.
- 각 사례에 호출 단계·결과·단계 지연·Provider 지연·요청/응답 바이트·토큰 수만 허용 목록으로 기록한다. 원문, Profile, 인용, 후보 값, 모델 원본 응답, API 키, 임의 오류 문자열은 저장하지 않는다.
- 전체 요약에 단계별 호출 수·중앙값·최대 지연과 시간 초과가 발생한 단계를 집계한다. 진단이 없으면 빈 목록으로 남겨 추정하지 않는다.
- 20건을 한 번씩 실행하고 기존 정확도·실패율 기준선과 함께 해석한다. 서로 다른 실행 간 차이를 코드 개선 효과로 주장하지 않는다.

## 완료 기준

- 성공과 실패 모두 안전한 단계 진단을 기록하며, 허용되지 않은 문자열을 산출물에 쓰지 않는다.
- Provider 시간 초과가 어느 단계에서 발생했는지 사례·집계로 확인할 수 있다.
- 단위 테스트 및 전체 테스트 통과, 합성 20건 실측 결과 기록, feature 브랜치 push.
