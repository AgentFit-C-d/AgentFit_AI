# 원문 수정 값의 경계
## 근거와 가설
직전 전체 파일럿의 Q006/N004는 수정 후 정답 표현을 포함했지만 값이 과도했고 검토가 거절했다. apply_repairs는 비부재 quote를 그대로 최종 값으로 사용한다. 프롬프트는 정확한 인용을 요구하지만 값과 근거 설명의 경계가 충분히 명확하지 않을 가능성이 있다.
## 실험
quote는 최종 표시 값이며 앞뒤의 근거 설명은 context에 둔다는 기존 계약을 명시한다. 부재일 때만 완전한 부재 문장을 quote로 사용한다. 필드의 역할·상태·공개 Profile·근거 검증·최대6회60초는 바꾸지 않는다.
실패2건과 사전 고정 새12건(10개 필드 양성, 부재, 미정)을 동일 입력에서 직접 수정 요청한다. 기존 prompt+예시와 명확화 prompt+예시만 비교한다. gold는 모델에 보내지 않는다.
