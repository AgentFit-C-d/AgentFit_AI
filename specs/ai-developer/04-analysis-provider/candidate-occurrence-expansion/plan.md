# 구현 계획 — 사용자 승인 완료
1. validate_quotes의 기본 동작을 보존하고 opt-in 위치 확장과 focus를 추가한다. 반복·중첩·Unicode·약어·CRLF·배치 간 ID·120개 경계·부분 성공 금지 테스트부터 작성한다.
2. AnchoredAnalyzer에 옵션과 별도 프롬프트 버전을 연결한다. 판정과 기존 후보 기반 재판정에 동일 focus를 제공한다. source_repair와 공개 Profile은 바꾸지 않는다.
3. 근거 위치 평가와 부재의 유효 경계 목록을 API 실행 전에 고정한다. 값이 같아도 잘못된 위치면 실패시키며 허용 목록 밖 예시·다른 제품·문서 전체 인용도 실패시킨다.
4. 고정 인용 후보의 판정만 비교하여 focus 효과를 분리한다. 동일 모델·추론·토큰·timeout을 사용하고 추출 누락은 이 평가 범위 밖임을 명시한다.
5. 초기 추출부터 기존 상태13건과 위치14건의 전체 흐름을 평가한다. 후보 수·누락·잘못된 확정/근거·실패·지연·호출 수를 기록한다.
6. 관문 통과 시 기존 전체12건3회와 위치 대조 반복을 수행한다. 실패하면 보존하고 반복 범위를 넓히지 않는다. 예약 공개 문서는 사용하지 않는다.
7. 독립 검토·최종 검증·feature 브랜치 commit/push. 실제 독립 문서·사용자 수정 부담 검증이 없으면 목표 완료를 선언하지 않는다.
