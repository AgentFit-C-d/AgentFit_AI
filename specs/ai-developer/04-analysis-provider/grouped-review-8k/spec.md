# 묶음 의미 검토 8,192토큰 평가 실험

## 근거와 목표

Campfire 공개 PRD의 3묶음 검토는 첫 묶음에서 유효한 의미 이슈를 찾았으나 둘째 묶음이 4,096토큰 상한에 도달해 끝나지 않았다. 사용자는 응답 시간을 현재 우선 제약에서 제외했고, 평가 전용으로 묶음당 8,192토큰을 시험하도록 승인했다. 모든 묶음이 완주하는지와 의미 정확도를 관측한다.

## 계약

- `--source-selector --grouped-review --accuracy-first --extended-review-window --group-review-8k`에서만 각 묶음의 출력 상한을 8,192토큰으로 바꾼다. 다른 구성의 묶음 검토는 4,096토큰이다.
- 원문·그룹 A/B/C·Profile·서버 검증·최대 6호출·600초 전체 기한·기본 서비스는 유지한다. 8,192토큰 옵션을 다른 분석 모드나 짧은 기한과 조합하면 CLI가 거부한다.
- plan에는 실제 묶음 출력 상한을 기록한다. 원문·응답 원본·키·Profile을 공개 평가 파일에 남기지 않는다.
- 이미 튜닝한 Campfire PRD 1건을 평가한다. 세 묶음이 검증되고 오확정이 없을 때만 같은 튜닝 PRD 5건으로 확대한다. 공개 부분 정답 밖 값은 사람 검토 전까지 정확하다고 주장하지 않는다.

## 완료 판단

- 기본 4,096토큰과 선택형 8,192토큰이 각각 실제 전송 payload 및 plan에 기록되고, 잘못된 옵션 조합이 거부된다.
- 전체 테스트와 Linux CI가 통과하며 실제 결과의 묶음별 완성·검증·출력 사용량·부분 정답·미평가 값이 기록된다. 실사용 승격에는 독립 문서와 확인 전 저장 금지 E2E가 별도로 필요하다.
