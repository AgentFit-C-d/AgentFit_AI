## 질문과 고정 조건

v3는 앞쪽 중첩 표현을 별도 대표로 남기고 뒤쪽6개를 미대표로 돌렸다. 후보 배열 순서가 이 결과에 영향을 주는지 진단한다. 문서 순서의 인과 효과나 모델 전체 정확도 검증은 아니다.

- 제품 코드0e51a48, 같은 승인 H02·완료 GLM snapshot·41개 기능 발생 위치·모델/프롬프트/출력8192/timeout600을 유지한다.

- 새 tmp 드라이버·결과 파일로 최대2호출,재시도0. 입력 반전 조건을 전송 전 assert한다. 기존v1/v2/v3 실패와 결과를 보존한다. 원문/키/응답 전문은 저장하지 않는다.

- 의미 검토가 통과하더라도 바뀐 모든 다중 그룹과 미포함 후보를 로컬 원문 대조한다. 후속 품질 개선 판단은 구조 유효성만으로 하지 않는다.

## 후속 결정

역순을 제품 기본값으로 적용하지 않는다. 다음 SDD 후보는 대표 자신/미대표의 결정 가능한 상태를 서버가 계산하고, 모델에는 서로 다른 대표-구성원 발생 위치의 포함 관계만 명시적으로 판단하게 하는 방식이다. 검토 오류나 미포함은 계속 확인 필요이며, 과도한 그룹의 복구와 이미 잘못된 확정 분류는 별도 문제로 남긴다. 구조 변경 후에는 고정된 원래/역순 두 분할로 평가하여 생성 변동과 검토 변동을 분리해야 한다. 이 단계에서 새 구조의 제품 코드는 작성하지 않았다.
