# 원문 선택자 분석의 간결 의미 검토 실험

## 목적

원문 선택자 분석의 의미 검토가 8,192토큰을 채우거나 긴 생성 끝에 시간 초과하는 문제를 줄인다. 기존 `compact_review` 계약을 선택형으로 재사용해 모델은 오류 항목 ID와 종류만 짧게 반환하고 서버가 기존 항목의 근거 줄을 계산한다. 기본 서비스·공개 Profile·확정 기준은 유지한다.

## 근거와 제한

- Solar Pro4/DeepSeek의 동일 긴 기한 공개 PRD 5건은 각각 자동 완료 0건이었다. Solar Campfire의 의미 검토는 `completion_tokens=8192/8192` 뒤 미완료됐고, 16,384토큰 재실행은 300초 기한을 소진했다.
- 기존 AnchoredAnalyzer의 간결 검토는 합성 20건에서 요청 중앙 크기와 지연을 줄였지만 형식·검증 오류가 늘어 기본값이 되지 않았다. 이 문제를 고려해 실패 시 자동 통과시키지 않는다.
- 이미 튜닝에 사용한 공개 PRD만 검증에 쓸 수 있어 독립 실서비스 품질 증거는 별도로 필요하다.

## 계약

- `--source-selector --compact-review`를 지정했을 때만, 현재 원문 선택자 Profile 초안에 기존 `compact_review.review_payload`를 적용한다. Solar와 NVIDIA 선택형 분석기 모두 같은 정규화를 사용한다.
- `normalize_compact_review`가 결과를 기존 `checkedFields/issues`로 변환·검증한 뒤 기존 의미 수정/재검토 경로에 전달한다. 잘못된 ID, 줄, null, 중복, 누락 근거는 `SEMANTIC_REVIEW_INVALID`로 보류한다. 오류를 `issues=[]`로 바꾸지 않는다.
- 간결 응답의 출력 상한은 현재 계약의 4,096토큰이다. 평가 계획 JSON은 실제 상한을 기록한다. 전체 기한·호출 수·원본 보관 정책은 현행 선택형 설정을 따른다.
- 간결 검토가 출력 상한에 닿으면 검토 호출의 `reasoning_effort`만 `medium`에서 `low`로 바꾸는 opt-in 비교를 허용한다. 추출·수정 모델 설정, 정답, 검토 schema는 유지한다. `low`가 응답을 완성해도 의미 정확도·오확정 검증 없이 채택하지 않는다.

## 검증 기준

- 정상·오류 모의 응답에서 정규화, 의미 수정 대상, 잘못된 ID 안전 실패, 기본 검토 계약 불변을 테스트한다.
- Campfire 1건으로 응답 길이·상태를 시험하고 구조/의미 검증을 통과하면 고정 PRD 5건으로 확대한다. 완료·부분 정답·오확정·미평가 값·시간·형식 오류를 기록한다. 개선이 입증되지 않으면 기본값을 바꾸지 않는다.
