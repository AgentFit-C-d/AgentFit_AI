# 분리 검토 호출 진단

H02 분리 검토가 667초 후 INCOMPLETE_RESPONSE로 끝났으나 후보 묶음인지 원문 누락 검사인지, length 종료인지 알 수 없다. 설정을 추가 튜닝하기 전에 호출 단위 증거를 수집한다.

- 선택형 CLI `--review-diagnostics`는 `--split-review`와 함께만 허용한다. 내부 `review_calls` 수집기로 후보 묶음 번호·후보 수 또는 원문 누락 단계, 호출 시간, 토큰 수, 허용된 종료 사유, 검증 성공 여부와 안전 오류 코드를 기록한다.
- 기존 Solar `_trace`를 재사용하고 finish_reason은 고정 allowlist로 추가한다. raw/message/원문/선택값/정답/키/예외문은 결과에 복사하지 않는다. 응답 원본을 파일에 저장하지 않는다.
- 호출 또는 응답 계약 실패 시에도 이미 수집한 메타데이터를 평가 행에 보존한다. 수집을 켜도 모델 입력, 호출 수, 보류 조건은 동일하다.
- 기본 서비스와 공개 Profile, 실험 판단 설정은 변경하지 않는다. 사용자 자율 진행 승인 범위 안에서 수행한다.

완료: 실패 마지막 호출의 단계·안전 메타데이터 보존, 민감 내용 제거, 수집 유무의 요청 동일성 테스트 및 전체 테스트/CI. 다음 실험은 승인된 H02 한 번이며 앞선 중단 실행은 재사용하거나 성공으로 세지 않는다.
