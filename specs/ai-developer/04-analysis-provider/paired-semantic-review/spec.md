# 정답/누락 초안 쌍 검토
현재 검토가 누락을 통과시키고 지연도 크다. 검토 단계만 분리해 정답 초안4건과 필수 필드 누락 초안4건을 비교한다.
source/gold/profile은 호출 전에 고정한다. 검토에는 원문·초안만 보내고 골드는 보내지 않는다.
현재 프롬프트/스키마/8192토큰/40초를 유지하고 reasoning_effort none/low만 바꾼다.
오통과, 오거절, 구조오류, 시간초과, 시간/토큰을 따로 기록한다. 각8건1회이며 실사용 게이트가 아니다.

## 후속 실험 범위
출력 계약 JSON 예시를 검토 프롬프트에 선택적으로 추가한다. review_examples의 기본값은 False이며 공개 Profile, 서비스 기본 분석기, 최대 6회/60초는 유지한다. 검토 단독 비교 이후 고정 12건의 전체 경로를 평가한다.
