# 검증 결과
## 검토 단독 쌍 평가
정답 초안과 누락 초안 4쌍을 각 조건에서 1회 평가했다. Mini4, 동일 스키마, 8192토큰, 40초 상한이다.

| 설정 | 완전 일치 | 의미 일치 | 시간 중앙값 |
|---|---:|---:|---:|
| none | 2/8 | 2/8 | 0.85초 |
| low | 8/8 | 8/8 | 26.76초 |
| none + 출력 예시 | 5/8 | 6/8 | 0.52초 |
| low + 출력 예시 | 8/8 | 8/8 | 5.48초 |

의미 채점 revision2는 허용된 중복 근거 줄 번호 [1,1]을 [1]과 동일하게 취급한다. 기존 결과는 수정하지 않았으며 별도 rescore-summary.json으로 집계했다. 필드·종류·항목 인덱스·근거 줄 내용은 계속 일치해야 한다.

## 전체 경로
Mini4/v2/원문 수정/수정 예시/low 검토/검토 예시의 고정 합성 12건은 **9/12 통과**했다. 시간 중앙값 7.98초.
- Q-001: SEMANTIC_REVIEW_INVALID. 정확한 위반 항목은 현재 진단에서 알 수 없다.
- Q-006: 분석기는 성공했지만 최종 gold 불일치. 잘못된 기능 표현을 수정·재검토가 해결하지 못했다.
- N-004: 수정 이후에도 gold 불일치, 재검토에서 SEMANTIC_REVIEW_INVALID.
- 나머지 9건 통과. 실패가 있어 계획한 추가 2회 반복은 실행하지 않았다.

이전 원문 수정 파일럿 3/12보다 관측 통과 수가 증가했다. 수정 예시와 검토 예시가 함께 바뀌었으므로 검토 예시만의 효과로 해석할 수 없다. 반복 평가가 아니며 같은 합성 자료를 튜닝에 사용했으므로 일반화 성능이나 실사용 가능성을 증명하지 않는다. 공개 예약 문서와 실제 문서는 이번에 전송하지 않았다.

## 코드 검증
전체 unittest 274건 통과. 공개 Profile 및 기본 설정 변경 없음. 성공 원문·추론 응답은 평가 파일에 저장하지 않으며, 보관된 결과는 수치와 제한된 오류 메타데이터다.
