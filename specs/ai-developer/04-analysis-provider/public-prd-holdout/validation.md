# 공개 PRD 독립 평가 검증 기록

## 준비 상태

- 2026-09-29: 공개 GitHub PRD 5건의 파일 크기와 Git blob ID를 확인했다.
- 각 저장소의 기본 브랜치 HEAD 커밋을 `sources.json`에 고정했다.
- 고정 raw 파일을 다시 내려받아 5건 모두 SHA-256 일치, UTF-8 디코딩 성공, 100,000바이트 이하임을 확인했다. 크기는 순서대로 8,850 / 22,483 / 32,985 / 96,718 / 23,970바이트다.
- 기존 분석 명세 폴더에서 해당 프로젝트명·저장소명은 검색되지 않았다. 다른 외부 사용 이력까지 증명하지는 못한다.
- 모델 호출, 수작업 정답 작성, 평가 실행은 아직 하지 않았다. 이 문서와 `sources.json`은 평가 완료 근거가 아니다.

## 원문 해석 주의

- `gongsi-mcp` PRD는 스스로 현재 구현과 다른 역사 문서라고 밝힌다. 평가는 이 PRD의 기획 내용만 대상으로 한다.
- `TrueTwo` PRD는 별도 product brief를 참조한다. 입력에 포함되지 않은 외부 문서는 정답 근거로 사용하지 않는다.
- `DeReel` PRD에는 잠정 기술 스택과 Phase별 계획이 섞여 있다. 확정 필드로 단정하지 않도록 정답 작성 시 상태를 구분한다.
