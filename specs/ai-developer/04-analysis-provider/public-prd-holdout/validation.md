# 공개 PRD 독립 평가 검증 기록

## 준비 상태

- 2026-09-29: 공개 GitHub PRD 5건의 파일 크기와 Git blob ID를 확인했다.
- 각 저장소의 기본 브랜치 HEAD 커밋을 `sources.json`에 고정했다.
- 고정 raw 파일을 다시 내려받아 5건 모두 SHA-256 일치, UTF-8 디코딩 성공, 100,000바이트 이하임을 확인했다. 크기는 순서대로 8,850 / 22,483 / 32,985 / 96,718 / 23,970바이트다.
- 기존 분석 명세 폴더에서 해당 프로젝트명·저장소명은 검색되지 않았다. 다른 외부 사용 이력까지 증명하지는 못한다.
- 소스 목록 고정 당시에는 모델 호출과 정답 작성 전이었다. 아래 정답 작성 후에도 평가 실행은 아직 하지 않았다.

## 모델 호출 전 수작업 정답

- 2026-09-29: `manifest.json`에 5개 PRD의 양성 점검 35개와 명시적 미정 필드 5개를 기록했다. 고정 원문 다운로드 후 모든 인용이 각 문서에 정확히 한 번 등장함을 검증했다.
- 총 50개 문서·Profile 필드 조합 중 38개 필드에 양성 또는 미정 정답이 있다. 나머지 12개 필드는 미평가이며, 양성 점검 35개는 기능 배열의 여러 항목을 포함한다. 부분 정답만으로 전체 정확도를 주장하지 않는다.
- 기존 공개 튜닝 매니페스트와 저장소·문서 SHA-256이 겹치지 않는다. 모델 전송 차단에 쓰이는 `_SENSITIVE` 패턴은 5건 모두 불일치했다. 이는 실제 비밀값 부재를 완전히 증명하지는 않는다.
- 선택적 `unknown_fields` 검증과 `public-evidence-v4` 집계를 실패 테스트부터 구현했고 공개 평가 테스트 23건이 통과했다. `null` 유지와 비 `null` 값은 구분하며 비 `null`을 미평가 값에도 중복 집계하지 않는다.
- 평가 예정 구성은 (1) 기본 추출 옵션, (2) `repair-context-options`와 `parallel-first-pass` 동시 사용이다. 두 구성 모두 `analyze_recoverable`, `solar-pro4`, 근거 계약, 의미 검토, 40초다. 아직 어느 구성도 모델 호출하지 않았다.

## 원문 해석 주의

- `gongsi-mcp` PRD는 스스로 현재 구현과 다른 역사 문서라고 밝힌다. 평가는 이 PRD의 기획 내용만 대상으로 한다.
- `TrueTwo` PRD는 별도 product brief를 참조한다. 입력에 포함되지 않은 외부 문서는 정답 근거로 사용하지 않는다.
- `DeReel` PRD에는 잠정 기술 스택과 Phase별 계획이 섞여 있다. 확정 필드로 단정하지 않도록 정답 작성 시 상태를 구분한다.
