# 명시적 배열 인덱스 검토 초안 실험

## 문제

기본 의미 검토의 형식 오류 중 `ARRAY_INDEX`가 재현됐다. 기존 검토 입력은 Profile 배열을 JSON 값 목록으로만 보여 주어 모델이 이슈의 0 기반 `itemIndex`를 스스로 계산해야 한다.

## 실험 설계

- 기본 Solar 모델·추출·수정·검토 스키마·검증 규칙·40초 제한은 유지한다.
- 선택형 검토 입력에만 배열 필드의 각 기존 값과 0 기반 `itemIndex`를 나란히 보여 준다. 누락(`missing`)은 기존 항목이 아니므로 `null`이라는 지침을 함께 둔다.
- 실제 서비스 Worker의 기본 동작은 변경하지 않는다. 검토 응답의 잘못된 인덱스를 추정·수정·무시하지 않는다.
- 같은 합성 사례를 기본/인덱스 안내 양쪽에서 각 1회, 순서를 교차해 실행한다. 완료·실패 사유, 정답, 오확정, 지연을 기록한다. 원문·Profile·모델 응답·키는 산출물에 저장하지 않는다.

## 채택 조건

인덱스 안내 방식은 `ARRAY_INDEX` 오류와 전체 실패를 줄이고, 오확정·정답률·60초 관측 지연을 악화시키지 않아야 한다. 소규모 선별에서 악화하면 확대와 기본값 변경을 중단한다. 동일 자료 재사용과 모델 변동성 때문에 한 번의 통과만으로 실사용 적합성을 선언하지 않는다.
