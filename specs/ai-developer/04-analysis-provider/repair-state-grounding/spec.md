# 수정 단계의 원문 상태 판단
## 문제
값 범위 v2는 수정 단독14/14 및 전체12건3회 통과했지만, 새 T07(개발 검증 모델/운영 제공자 미정)에 잘못된 missing 이슈를 주면 오답이 발생했다. 이전 기록만으로 특정 잘못된 값은 알 수 없다.
## 요구
원문 상태와 역할은 기존 초안/검토 이슈보다 우선한다. 미정은 null, 범주 전체 부재만 [], 부분 부정은 해당 후보만 제외한다. 현재 제품 채택 사실만 확정한다.
공개 Profile·스키마·검증·호출 한도는 유지하고 선택적 프롬프트 실험만 수행한다. 성공 원문·추론은 저장하지 않고 역할/상태 enum 및 수치만 진단한다.
