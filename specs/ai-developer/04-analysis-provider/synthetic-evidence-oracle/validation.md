# 검증 기록

## 범위

- 기존 Q/N 12건의 전체 필드값 gold에 근거 문구를 덧붙였다. E 8건은 현재 제품의 명시적 사실·부정만 필드별로 표기했고, 그 밖의 필드는 미채점으로 남긴다.
- 채점기는 값 불일치, 근거 문맥 불일치, 정답 누락, 미채점 제안을 분리한다. 결과 파일에는 숫자와 안전한 필드명만 저장하며 원문·Profile·키를 추가하지 않는다.
- 동일 표현의 역할을 구분하는 Q-002, 과거 기술을 현재 기술로 잘못 취급하는 E01, 근거에서 현재 제품 문맥이 빠지는 E02를 오프라인 회귀 테스트로 확인했다.
- 자료는 튜닝에 사용된 합성 사례이고 정답표는 AI 개발 측에서 작성했다. 사람의 독립 채점·실제 문서 일반화 증거가 아니다. `held_out_independent_documents=false`로 실사용 게이트를 통과할 수 없다.
- 전체 AI 서비스 단위 테스트 546건과 `git diff --check` 통과.

## 아직 검증하지 못한 것

- 수정 후 Solar의 실제 20건 호출과 새 채점 결과. 해당 원문의 Upstage API 전송에 대한 구체적 승인을 기다린다.
- 애매한 필드의 완전한 정답, 합성 밖 실제 기획서의 정확도, Spring·Frontend의 확인 저장 E2E.
