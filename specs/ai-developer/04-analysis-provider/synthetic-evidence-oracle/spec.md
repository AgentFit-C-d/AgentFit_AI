# 합성 20건 값·근거 채점 보강

## 목적

기존 복구형 분석 평가는 Q/N 12건의 필드값만 전체 비교하고, E 8건은 일부 target/forbidden만 채점한다. 근거의 의미 위치는 전부 미채점이다. 합성 문서에 한정한 필드·근거 정답표를 추가해 미채점 범위와 오류를 분리 집계한다.

## 범위와 한계

- Q/N 12건은 기존 전체 필드값 gold를 유지하고, 알려진 값·명시적 없음의 근거 문구를 추가한다.
- E 8건은 분명한 현재 제품 사실과 명시적 부정만 필드별로 표기한다. 애매한 필드는 `unassessed`로 남겨 오답/정답으로 만들지 않는다.
- 근거는 원문에서 정답 문구의 위치를 계산해 Profile 근거 구간이 해당 문구를 포함하는지 검사한다. 반복 표현은 문맥 문구로 구별한다.
- 결과 파일에는 원문·모델 Profile·키·인용문을 저장하지 않는다. 숫자와 안전한 필드명만 기록한다.
- 자료는 튜닝에 사용한 합성이며 독립 실제 문서 검증을 대체하지 않는다. 평가의 실사용 게이트는 `held_out_independent_documents=false`로 실패해야 한다.

## 수용 기준

1. 20건 정답표가 원문 내 인용 존재·필드 타입·중복 ID를 검증한다.
2. 알려진 오인용·부정된 기술·반복 문맥 오류는 안전 집계에서 감지하고, 애매한 필드는 미채점으로 남긴다.
3. 기존 평가 결과 파일의 비밀/원문 비저장 규칙과 6회·60초 관측 규칙을 유지한다.
4. 오프라인 테스트를 통과한다. 실제 Solar 재평가는 외부 전송 승인 후 별도로 실행한다.
