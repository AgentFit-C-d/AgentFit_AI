# 추출 오류 비교 리포트

## 목적
승인된 후속 진단: 기존 추출 평가의 실패 원인을 구분한다. 서비스 API, 프롬프트, 정답, 점수 기준은 유지한다.

## 계약
- 기존 3종 정답 형식 지원: 전체 튜플, 명시적 부재, 부분 역할 정답.
- 정확 값의 다중집합으로 대응한다. 같은 값의 반복 후보도 개수를 유지한다.
- 정확 값 미대응은 missing_exact/extra_exact로 보고한다. 의미적 누락/환각이라고 단정하지 않는다.
- 같은 값 묶음의 field/role/status/scope 분포를 비교한다. 차원별 최소 불일치 수이며 합산한 오류 개수가 아니다.
- 부재 정답은 필드로 대응하고 null·허용 역할·absent·current 여부를 따로 본다.
- 부분 정답은 명시된 기준만 검사한다. 나머지 차원은 미평가한다.
- 근거 문맥은 별도로 검사한다. 중복 후보의 임의 매칭은 하지 않는다.
- 후보 번호, 정답 번호와 정확 일치 관계, 허용된 분류값, 정수 위치만 기록한다. 원문·인용·자유 텍스트·응답 원본을 기록하지 않는다.
- 기존 score가 합격 여부의 유일한 기준이다. 리포트는 설명용이며 불일치가 없더라도 합격으로 바꾸지 않는다.

## 검증
합성 테스트 후 기존 6사례를 none/low 각1회 평가한다. 이전 결과는 원본이 없으므로 소급 분석하지 않는다.
정답과 프롬프트 해시를 비교하고 변동 가능성·정답의 한계를 명시한다.
