# 조사 기록
기준 커밋은156b651이다. 직전 목표 작업은 구현·대조 실험·원격push로 실제 진행이었다. 실사용 목표는 미달이며 실행 중인 API 작업은 없다.

## 확인한 기존 설계
section-decisions, independent-classification의 명세·결과, anchored-candidates 명세, factual-questions 명세, api-contract-probe 결과를 읽었다.
기존 단일 선택은 추출 단계의 분류를 유지했다. 이번 제안은 분류 없는 원문 후보에서 필드와 채택 의미를 단일 라벨로 고른다.

## 중요한 차이
merge_profile은 제외된 confirmed/current 후보도 충돌 검사에 사용한다. 새 omit은 그 정보를 잃으므로 명세에 검증 차이와 회귀 관문을 명시했다.
출력 복잡도가 의미 오류의 원인이라는 가설은 미입증이다. 새 계약은 승인 전에 구현하지 않는다.

## 명세 자체 검토
라벨은 일반값11개·부재5개·omit/conflict2개로 총18개다.
공개 Profile과 호출 예산은 유지하되 내부 응답 형식과 제외 정보는 바뀐다. 기존 충돌 검증과 동등하다고 주장하지 않는다.
새 후보의 효과·실사용 준비를 가정하지 않으며, 통과 전 추가 반복과 예약 공개문서 사용을 금지한다.
