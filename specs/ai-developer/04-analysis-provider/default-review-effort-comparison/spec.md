# 기본 의미 검토 추론량 비교

## 배경

기본 Worker의 Solar 분석은 합성 20건 재측정에서 40초 시간 초과가 9건이었고, 모두 의미 검토에서 발생했다. 검토 설정은 `reasoning_effort=medium`, 최대 8192 토큰이다. 추론량을 낮추면 지연이 줄 수 있지만 의미 오류를 놓칠 수 있다.

## 실험 계약

- 기본 Worker와 같은 Solar 모델·추출 프롬프트·근거 계약·40초 기한·의미 검토를 사용한다. 의미 검토 호출의 `reasoning_effort`만 `medium`과 `low`로 다르게 한다. 실제 Worker 설정은 바꾸지 않는다.
- 동일한 합성 사례를 두 팔에서 각 1회 실행하며 짝수·홀수 사례의 실행 순서를 교차한다. 원문·Profile·원본 응답·키는 저장하지 않는다.
- 사례별 완료·실패·정답·오확정·단계 지연을 기록하고 두 팔의 전체 및 양쪽 완료 사례를 별도로 집계한다.
- 시간 초과 감소만으로 채택하지 않는다. `low` 팔은 오확정이 늘지 않아야 하며 실패·정답도 악화되지 않아야 한다. 비교 결과가 자료 재사용과 호출 변동성의 영향을 받는다고 명시한다.

## 완료 기준

- 설정 차이가 의미 검토 호출에만 적용됨을 테스트로 확인한다.
- 안전한 산출물과 순서 교차·짝 비교를 테스트한다.
- 합성 사례를 실행해 시간·정확도·오류의 분포를 기록하고 기본 Worker 변경 여부를 근거로 결정한다.
- 전체 테스트 통과 후 feature 브랜치를 push한다.
