# 계획
1. 서로 다른 표현 오류 6종의 정답/오답 초안 12건을 사전 고정: 행위자 포함 단일 동작, 제목 접두사, 복수 동작 묶음, 운영 모델 이름 범위, 거부 모델 포함, 명시적 외부 연동 부재.
2. 모든 초안은 원문 근거 검증을 통과해야 한다. 의미 오류는 별도 검토 대상.
3. Mini4/low/출력예시/8192토큰/40초로 기준선12건 실행 후 표현 경계 문구만 수정한12건 실행.
4. 전체 이슈 정확 일치와 오수락·오거절·구조 오류·시간을 구분한다. 이미 틀린 초안을 단순 거절한 것과 정확한 수정 지시를 구분한다.
5. 개선 증거가 있을 때만 전체 경로 opt-in 연결을 다음 단계에서 검토. 기본값 변경 없음.

## 비교 변수
개정 프롬프트는 표현 경계(단일 동작 주어 허용/목록 접두사 및 복수 동작 제외/제공자 이름 범위)와 기존 배열 itemIndex 작성 규칙의 재강조를 포함한 한 버전이다. 두 요소의 개별 효과를 주장하지 않는다. 스키마나 검증 허용 규칙은 바꾸지 않는다.

## 전체 흐름 후속
쌍 비교는 정확 일치7/12→11/12, 수락/거절10/12→12/12다. 기본False인 review_expression 옵션으로 동일 프롬프트를 연결한다. 기존 수정 예시는 유지하며 이전 고정12건을 1회 평가한다. 모두 통과하지 않으면 확장 반복 없이 실패 원인을 기록한다.
