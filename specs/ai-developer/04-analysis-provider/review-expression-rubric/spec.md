# 표현 경계 검토 실험
기존 실사용 명세는 기능의 행위자·행동·대상 보존 및 사전 등록 별칭을 요구한다. 기존 검토 문구는 주어·조사·서술어의 과도한 범위를 경고해 올바른 동작 문장도 거절할 수 있다.
한 개 동작의 행위자/대상/서술어는 허용하고 제목·범주 접두사·복수 동작 묶음은 거절하는 명확한 규칙을 별도 실험한다. AI/외부 연동 이름은 선택 문장 전체가 아니라 제공자 이름을 값으로 사용한다. 기존 공개 Profile·근거 검증·서비스 기본값을 유지한다.
정답 기준을 낮추거나 기존 gold를 바꾸지 않는다. 평가 전 새 합성 정답/오답 6쌍을 고정한다. 한 번의 정답률로 실사용 판정을 내리지 않는다.
