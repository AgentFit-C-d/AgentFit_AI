# 동일 초안 기반 리뷰 모델 비교 명세

## 목적

Solar Pro4와 DeepSeek V4.1 Flash의 의미 검토 효과를 후보 추출·판단의 비결정성과 분리해 비교한다. 이 평가는 이미 튜닝에 사용한 합성 20건의 진단 실험이며 서비스 준비 판정이 아니다.

## 요구사항

- 각 문서에서 Solar 후보 생성과 판단을 정확히 한 번 실행한다. 최초 의미 검토 직전의 응답과 요청 지문을 메모리에만 보관한다.
- 두 평가군은 기록된 상류 응답을 같은 순서로 재생한다. 요청 내용이 달라지면 재생을 거부한다. 의미 검토·필요한 수정·재검토는 각 평가군에서 실제 호출한다.
- 두 평가군은 동일한 compact 검토 계약, 후보 설정, 40초 호출 상한, 최대 6회·60초 분석 예산을 사용한다. 상류 실행 시간은 각 평가군의 가상 총 시간에 더하고 남은 시간 예산에서 차감한다.
- 상류 실패는 두 평가군 공통 실패로 별도 기록한다. 해당 사례로 모델 우열을 판단하지 않는다.
- 전체 Profile 정확도·완전 일치·오확정·검증 실패와 단계별 리뷰 오류·시간을 고정 분모와 짝별로 보고한다. 결과 파일에는 원문, 원본 응답, API 키, 요청 본문을 기록하지 않는다.
- 입력·코드 지문, 상류 응답 지문, 재생 동일성, 평가군 순서를 기록한다. 지문은 응답 내용 자체를 복원하지 못하도록 HMAC으로 계산하고 키는 기록하지 않는다.
- 기본 분석기와 공개 Profile 계약은 변경하지 않는다.

## 판정

짝지은 입력에서 DeepSeek가 Profile 정확도·완전 일치·오확정을 악화시키지 않고 검토 오류/시간을 개선할 때만 실제 문서 후속 검증 후보로 삼는다. 합성 자료만으로 기본 모델을 바꾸지 않는다.
