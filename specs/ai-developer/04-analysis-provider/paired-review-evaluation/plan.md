# 구현 계획

1. 평가 전용 상류 캡처와 엄격한 메모리 재생을 만든다. 최초 리뷰 전에만 중단하고 요청 지문, 응답, 소요 시간을 수집한다.
2. 두 평가군의 리뷰·후속 수정 흐름을 기존 `AnchoredAnalyzer`로 실행한다. 재생 시 원 요청과 다르면 실패하고 상류 이후만 실제 Solar/NVIDIA API로 보낸다.
3. 상류 시간 차감, 공통 실패, 재생 검증, 비밀 데이터 비기록을 단위 테스트로 검증한다.
4. 기존 합성 20건에서 짝 비교를 실행하고 이전 독립 실행과 구분해 집계한다. 정해둔 판정 기준으로 결과를 해석한다.
5. 변경 파일과 테스트 결과를 검토한 뒤 `feature/paired-review-evaluation` 브랜치에 커밋·push한다.

## 제약

- 중간 응답은 실행 중 메모리에만 존재한다.
- 두 평가군의 후속 수정은 서로 다른 리뷰 결과로 달라질 수 있다. 이 차이는 리뷰 모델의 영향으로 취급한다.
- 제공자 상태의 시간 변동과 합성 데이터 재사용 때문에 결과를 일반화하지 않는다.
