# 동일 초안 기반 모델 비교 결과

## 실행

- 합성 20건, Solar Pro4 후보·판단은 문서당 1회만 실행했다. 각 평가군은 같은 상류 요청·응답을 메모리에서 재생했다.
- 상류 실패 `SECTION_MERGE` 4건은 두 모델 공통 실패로 기록하고 모델 비교에서 제외했다. 나머지 16건의 양쪽 재생 검사는 모두 통과했다.
- `python -m unittest discover -s tests`: 383건 통과.
- 결과 파일에서 전체 입력 문서·두 API 키가 발견되지 않았고, 실행 코드 SHA-256이 계획 파일과 일치했다.

## 결과

| 지표 | Solar Pro4 검토 | DeepSeek V4.1 Flash 검토 |
|---|---:|---:|
| 전체 Profile 완전 일치 | 7/16 | 7/16 |
| 일반 사례 완전 일치 | 6/11 | 7/11 |
| 다구역 사례 완전 일치 | 1/5 | 0/5 |
| 일반 사례 정답 필드 수 | 60/110 | 79/110 |
| 다구역 정답 항목 수 | 3/16 | 0/16 |
| 오확정 | 0 | 0 |
| 검증 오류 | 6 | 3 |
| 의미 검토·재검토 호출 시간 초과 | 3 | 5 |

정답 수는 분석이 오류로 끝난 사례를 0점 처리한 고정 분모 집계다. 일반 사례에서 DeepSeek의 유효 결과가 많았지만 다구역 사례에서는 Solar만 1건 성공했다. 완전 일치 총수는 같다. DeepSeek의 검증 오류는 적었지만 리뷰 시간 초과는 더 많았다.

## 판정과 제약

- 지정한 통과 조건 중 다구역 정확도 비악화, 성공 건수 증가, 가상 60초 관측 조건을 만족하지 못했다. 최대 관측 가상 시간은 약 60.1초로 제공자 호출의 경계 초과가 있었다. **기본 리뷰 모델은 Solar Pro4로 유지한다.**
- 상류 동일화로 앞선 독립 실행의 주요 혼선을 제거했지만, 후속 수정·재검토는 리뷰 결과에 따라 서로 달라질 수 있다. 제공자 부하와 시간 변동도 남는다.
- 합성 자료는 이미 튜닝에 사용됐다. 이번 결과는 서비스 준비성이나 새로운 문서에서의 일반화를 입증하지 않는다.
