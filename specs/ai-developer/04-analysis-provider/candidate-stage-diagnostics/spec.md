# 후보 단계별 정답 도달 진단

H02에서 정확한 원문 후보는 37개에서 138개로 늘었지만 최종 양성 정답 일치는 4/6에 머물렀다. 누락이 생긴 단계를 확인하기 위한 선택형 평가 진단을 추가한다.

- 후보 우선 분석은 선택적 관측 함수에 위치 고정·판정·검토 후·최종 투영의 깊은 복사본을 전달한다. 기본 경로에는 관측 동작이 없다. 관측 함수가 모델 입력이나 분석 상태를 변경해서는 안 된다.
- 평가기만 정답을 가진다. 정답의 값 또는 확인 조건을 모델 요청에 주입하지 않는다. 단계별 결과는 정답 ID·필드·네 단계의 bool/null 및 최초 미일치 단계만 기록한다.
- 양성 정답은 기존 `contains_any` 조건을 그대로 쓴다. 위치 단계에서는 문구 존재만 확인하고, 판정 이후에는 해당 필드의 confirmed 후보만 센다. 최종 단계는 기존 Profile 채점기를 쓴다. `expect_null`은 최종 단계에서만 평가한다.
- 실행되지 않은 단계는 null로 남긴다. 모델 실패를 누락이나 정답으로 간주하지 않는다. 확인 필요 제안의 미일치 ID는 자동 완료 채점과 별도로 기록한다.
- 이 진단은 한정된 정답 항목의 누락 경로를 찾는 도구이며 전체 출력의 정확도·오확정률·서비스 준비도를 증명하지 않는다. 공개 서비스 응답은 바꾸지 않는다.
