# 원문 후보 ID 선택
## 목적과 범위
사용자의 후속 진행 승인에 따라 기존 기능 추출의 인용문/등장순번 생성 오류를 줄인다. 공개 Profile, Solar Pro4, 2회 추출+최대1회 수정, 비밀정보 차단, 실패 원문 7일 보관은 유지한다.
## 요구사항
- 서버가 원문 내 작은 구간(token)에 전역 정수 ID와 줄 ID, Unicode codepoint 시작/끝 위치를 부여한다.
- 모델은 기능마다 lineId/startId/endId/role만 선택한다. 서버가 시작 구간부터 끝 구간까지 원문을 복사한다. quote/occurrence는 허용하지 않는다.
- 단어·문장부호를 분리하고 한국어 어절 끝의 한정된 조사/종결 표현에 추가 경계를 제공한다. 어절 분석은 의미 판정이나 원문 변경이 아니다. 인접 구간을 합쳐 원래 표현을 선택할 수 있다.
- 선택 구간은 같은 줄, 정방향, 실존 ID, 1~200자여야 한다. bool ID, 추가 키, 30개 초과, 중복 선택, 알 수 없는 역할을 거절한다.
- 미언급 null, 명시적 없음 absenceLineIds와 역할 필터는 유지한다. 핵심 필드/외부연동 판정은 이번에 바꾸지 않는다.
- 후보 12,000개 초과는 잘라내지 않고 API 호출 전 실패한다. 모델에 전달하는 후보는 서버 내부 좌표의 텍스트/ID만이다.
## 검증
99개 기존 단위 회귀와 ID/반복/Unicode/경계/잘못된 선택/호출별 스키마 테스트. 고정 신규 역할8건, README2건, 기존합성24+2건, 기존실제4건 평가.
구조 오류 감소와 의미 정확도를 분리 보고한다. 루브릭을 수정하지 않는다. 목표는 모두 통과이며 실패하면 실험 상태로 기록한다.
