# 네 가지 사실 질문: 최종 비교 결과

## 조건
새 합성12사례를 고정하고 정순·역순 각각1회, 기존2축과 신규4질문으로 총48회 호출했습니다.
모델은 양쪽 모두 Solar Jev이며 원문과 인용은 같습니다. 사례별로 실행 순서를 교차했습니다.
기존 프롬프트는 변경하지 않았고 신규 프롬프트도 실행 후 튜닝하지 않았습니다.
공통 정답 단위는 adopt/exclude/unknown입니다. 개별 질문의 yes/no/unknown 정답은 별도로 집계했습니다.
정답은 개발 과정에서 작성한 임시 합성 기준이며 외부 검수된 실제 문서 정답이 아닙니다. 특히 '반대의 명시적 근거'와 미언급의 경계는 이 평가 정의에 의존합니다.

신규 방식은 최종정답22/24, 질문정답88/96, 순서일관12/12, 오채택0, 기존보다 높은 최종정답이라는 사전 기준에 미달했습니다.

## 결정별 상세
- 정답 adopt 4회: 신규는4회 모두unknown. 기존은4회모두adopt.
- 정답 exclude 14회: 신규exclude11/unknown3. 기존exclude9/adopt4/unknown1.
- 정답 unknown 6회: 신규unknown5/exclude1. 기존unknown6.

오채택0은 자동판정이 정확해졌다는 뜻이 아닙니다. 신규 방식은 전체24회에서 adopt를 한 번도 출력하지 않았습니다.
사용/제공의 명시적 긍정이 있어도 다른 질문을 no 대신unknown으로 답하면 서버의 엄격한 조건 때문에 미정으로 남습니다. 실제 채택 누락4회는 모델 답과 서버 정책을 합친 결과입니다.
따라서 이 실험은 Solar/Jev 자체의 일반 성능 한계를 확정하는 근거가 아닙니다. 현재 질문 정의·서버 정책 조합이 자동 확정 목적에 부적합하다는 결과입니다.
