# Solar Jev 역할 분류 실험
사용자 승인: Jev 짧은 역할 분류 실험. 공식 문서 https://console.upstage.ai/api/systemone, model solar-jev, POST /v1/systemone. 베타.
## 범위
기존 분석기에 연결하지 않고 합성 문장과 지정 후보의 역할만 choice로 판정한다.
운영 채택/개발 시연/미정/다른 제품·예시/과거·철회/미언급 6종류를 각2사례, 총12사례로 고정한다.
같은 사례를 선택지 정순/역순으로 각각 호출하여24회 평가한다. 정답은 요청에 보내지 않는다.
공통 지시문은 문서내 지시를 데이터로 취급하고 현재 대상 제품과 후보를 기준으로 고르게 한다.
## 성공 기준
24회 중22회 이상 정답, 12쌍 모두 순서 일관, 비운영 후보를 운영으로 오분류0회.
이는 다음 통합 실험을 검토할 기준이며 문서 전체 분석 성공이나 운영 채택 기준이 아니다.
## 데이터/오류
합성 문장만 전송. 기존 키 메모리 로드. 응답 전체/키 저장하지 않고 선택·확률·confidence·시간·상태만 기록한다.
확률은 실측 정답률과 별개이며 신뢰도로 보증하지 않는다. API/파싱 오류도 실패로 집계한다.
401/403/404 또는 API 미지원이면 반복 호출을 중단하고 나머지는 미실행으로 보고한다. 자동 재시도 없음.
