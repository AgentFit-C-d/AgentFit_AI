# 후보 위치 우선 Profile 분석 계획

1. [x] 원문 후보 정렬 결과를 안정 ID·정확한 값·근거 구간으로 고정하는 순수 함수를 실패 테스트부터 만든다.
2. [x] 10필드·상태별 판정 응답 스키마와 전체 ID 커버리지 검증을 만든다. 잘못된 ID·중복·누락은 실패 처리한다.
3. [x] 유효한 판정에서 Profile 초안을 결정적으로 구성한다. 반복·부정·검토안·스칼라 충돌·기능 수 제한은 확인 필요로 보류한다.
4. [x] LangExtract 후보 생성과 모델 판정을 선택형 경로로 연결하고 커버리지 검토를 넣는다. 기본 서비스는 유지한다.
5. [ ] 합성 및 비식별 개발 문서를 기존 분석기와 비교하고 오확정·누락·완료율·시간·호출 수를 기록한다. 현재 세 문서의 완료율과 한 문서의 시간만 수집했다. 자동 완료가 없어 오확정률을 측정할 수 없고 호출 수·동일 조건 시간 비교는 남았다.
6. [ ] 전체 테스트·Linux CI를 확인하고 `feature/candidate-first-profile`에 push한다. 실사용 승격 여부와 남은 검증 자료를 명시한다.
