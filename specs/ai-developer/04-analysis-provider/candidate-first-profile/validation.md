# 후보 위치 우선 분석 검증

## 범위

- 기본 서비스 경로는 변경하지 않았다. 이 결과는 선택형 내부 실험에 한정된다.
- 승인된 비식별 문서 H01~H03은 이미 개선에 사용된 개발 자료다. 독립 최종 검증군으로 간주하지 않는다.
- 평가 결과 파일에는 문서 원문·후보 값·키를 저장하지 않고, 안전한 집계만 남겼다.

## 실문서 관찰

| 문서 | 결과 | 고정 후보 | 보류 후보 | 검토 문제 | 확인 필요 필드 |
| --- | --- | ---: | ---: | ---: | --- |
| H01 | 확인 필요 | 48 | 25 | 3 | project_name, database, deployment, features |
| H02 | 확인 필요 | 51 | 43 | 3 | domain, deployment, features |
| H03 | 확인 필요 | 16 | 3 | 9 | project_name, features, external_integrations |

- 자동 완료: 0/3. 따라서 자동 완료 Profile의 정답률과 오확정률은 평가할 수 없다.
- H02 확인 필요 제안은 정답 항목 6개 중 4개와 일치했다. 제안의 일치율은 자동 완료율에 합산하지 않는다. H01·H03 제안은 이 지표가 추가되기 전에 실행돼 비교 수치가 없다.
- H02는 8,192 출력 토큰 설정과 `other` 후보 상태 정규화 후 끝까지 처리됐다. 그 이전 실행에서는 후보 생성 응답 불완전과 판정 계약 오류가 있었다. H03도 이전 실행에서 검토 시간 초과와 판정 실패가 있었으므로 모델 응답 안정성은 검증되지 않았다.
- H02 최종 실행 시간은 약 120초다. H01·H03의 실행 시간과 모델 호출 수는 동일 조건으로 수집하지 않아 비교하지 않는다. 이 파일럿은 기본 분석기와 같은 조건의 속도 비교가 아니다.

## 자동 테스트

- `python -m unittest discover -s tests -q`: 807건 실행, 6건 건너뜀, 나머지 통과 (Windows 로컬 가상환경).
- 정확한 인용 위치, 모호한 반복 인용 보류, 전체 ID 판정, 충돌 및 기능 수 제한, 검토 누락, 실패 단계 표시는 단위 테스트로 확인했다.

## 승격 판단

현재 기본 분석기로 승격하지 않는다. 세 문서 모두 수동 확인이 필요하고, 새 자료에 대한 독립 검증·실제 Spring 입력 경로 검증·오확정 0건 관문이 남았다. 후보 생성 누락과 반복 인용의 모호성, 모델 응답 안정성이 주요 개선 대상이다.
