# 후보별 단일 판정
## 근거와 범위
section-v1 ROLE-002에서 F0006/F0008이 선택과 제외에 동시에 나타나 SECTION_MERGE로 실패했다.
내부 실험의 통합 응답만 후보ID별 단일 판정으로 바꾼다. 공개 Profile, 구역 추출, 기본 SolarAnalyzer와 6회/60초 예산은 유지한다.
## 요구사항
- 응답은 decisions 객체 하나이며 서버가 제공한 모든 후보ID가 정확히 한 번 필요하다.
- 값은 selected 또는 기존 제외 사유 enum 하나다. 서버가 후보의 field를 사용해 Profile을 구성한다.
- 누락, 미지ID, 잘못된 판정, 과거 fields/excluded 응답, 중복 JSON 키는 거절한다.
- 역할/확정/범위, 스칼라 충돌, absence 충돌, 중복값, 필드 개수 제한을 유지한다.
- 빈 후보 풀은 빈 decisions이며 전체 Profile 값은 null이다.
- 의미 수정도 같은 계약을 사용한다. 제외 사유의 의미적 정확성은 독립 검토 대상이다.
## 완료 기준
회귀 및 전체 테스트 통과, 실제 Solar의 고정 후보 통합 재현, 기존 7사례 비교를 기록한다.
원본 추출의 값/인용 불일치와 timeout은 이번 변경으로 해결됐다고 주장하지 않는다.
