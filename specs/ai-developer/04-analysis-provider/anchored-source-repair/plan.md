1. 원문 단위 기반 수정 응답 스키마/검증기/필드 교체 함수를 회귀 테스트부터 작성한다.
2. 후보 밖 새 인용으로 누락이 복구되는 테스트, 한 후보의 여러 동작 분리, 부재/미정 보존, 중복 인용·명령문·다른 필드 수정 거절을 검증한다.
3. 6회/60초·원자적 실패·비대상 필드 보존·실패 보관 정책을 검증한다.
4. 고정 기존6+새6에서 기본경로와 수정경로를 비교한다. 초안·검토 탐지·수정 후 점수와 시간/토큰을 분리한다.
5. 전체12건 의미 통과·중대 오확정0·정확근거100%를3회 만족한 뒤에만 기존 실제 튜닝 문서로 확대한다.
6. 미달하면 실패 원인을 보존하고 공개 최종 검증 자료는 사용하지 않는다.
7. 별도 feature/anchored-source-repair 브랜치에 구현·검증·commit/push. 이 문서는 구현 승인이 아니다.
