# API 계약 최소 재현

사용자가 추가 보완을 승인하여 진단을 재개한다. 공개 Profile 및 기본 분석기는 유지한다.
신규 합성 4사례: 사용자 기능, 운영 AI, 개발 전용, 도입 검토.
지정 후보를 포함한 문장 하나를 정확히 인용하고 역할·상태를 반환한다.
Mini4 별칭, temperature 0, frequency_penalty 0, max_tokens 4096, timeout 40초.
비교: schema-none / schema-reverse-none / json-object-none / schema-low.
각 사례 2회, 총 32회. 메시지는 동일하며 정답을 보내지 않는다. 두 번째 반복은 설정 순서를 역전한다.
구조·인용·역할·상태·전체 일치와 반복 일관성을 별도 집계한다. 오류도 분모에 포함한다.
원본 응답 및 reasoning은 저장하지 않는다. 검증된 라벨·일치 여부·안전한 메타데이터만 기록한다.
개발자가 작성한 소규모 임시 정답이다. 8/8도 서비스 품질을 보증하지 않는다.
설정 차이는 후속 검증 대상으로 삼으며 전체 문서 기본 설정을 자동 변경하지 않는다.

## 실행 전제 수정
스냅샷 직접 요청은 HTTP 400 invalid_request_body로 32건 모두 거절됐다. 별도 진단 1건에서도 재현했다. 별칭 요청 1건은 성공했다. 본 비교는 별칭으로 다시 32건 실행하며 실제 응답 모델을 기록한다. 최초 실패 기록은 별도 보존하고 의미 정확도 비교에서 분리한다.
