# 구현 계획

1. Solar 성공·검토 실패·구조 실패에서 보존할 스냅샷과 확인 질문을 테스트로 고정하고 실패를 확인한다.
2. `SolarAnalyzer`에 기본 동작이 없는 관측 훅을 두고, 선택형 `RecoverableSolarAnalyzer`가 검증된 전체 Profile·검토 이슈만 요청 범위에 저장하도록 구현한다.
3. 기존 `project_draft`에 미검토 제안 질문 및 null 일괄 질문 억제 옵션을 추가한다. 기본 Anchored 호출의 출력은 유지한다. 이슈 제거 후 제안 0개 응답은 실패로 돌린다.
4. 구조·보안·동시성 관련 테스트와 전체 테스트를 실행하고 합성 사례에서 실패→확인 필요 전환 및 제안 정오를 평가한다. 실제 20건 평가에서 드러난 제안 0개 결함을 회귀 테스트로 고친 뒤 재채점한다.
5. 검증 한계와 서비스 연결 전제 조건을 기록하고 `feature/recoverable-solar-analysis`를 push한다.
