# NVIDIA 원문 선택자 전체 분석 비교

## 목적

Solar Pro4에 고정된 원문 선택자 실험을 NVIDIA NIM 모델에서도 같은 문서·필드·선택자·의미 검토 계약으로 실행한다. 모델별 전체 분석의 완료, 누락, 오확정, 지연을 관찰해 실서비스에 쓸 모델 선택 근거를 만든다. 기존 Solar 기본 서비스와 공개 Profile은 유지한다.

## 범위와 경계

- 첫 대상은 과거 고정 후보 판정에서 가능성을 보인 `deepseek-ai/deepseek-v4.1-flash`다. 같은 공개 PRD 5건은 이미 튜닝 자료이므로 독립 최종 검증으로 사용하지 않는다.
- 모델은 후보 추출, 수정, 의미 검토, 재검토 전체를 맡는다. 원문 선택자와 공개 평가 채점은 Solar 실험과 동일하다. NVIDIA 전용 요청 옵션은 기존 `nvidia_payload` 변환을 사용하고, 반환 모델명 일치와 안전한 응답 파서를 검증한다.
- 비교 CLI의 NVIDIA 모델 선택은 `--source-selector`와 함께만 허용한다. 선택하지 않으면 현행 Solar Pro4 경로다. 비밀 키는 `.env`에서 읽되 결과 파일에 저장하지 않는다. 실제 원문·원본 응답도 결과 파일에 남기지 않는다.
- 사용자 결정에 따라 이번에는 정확도를 먼저 본다. 실험 전용 전체 기한 300초·필드 호출 상한 120초를 허용하고 최대 6회는 유지한다. 기본 서비스의 60초 설정과 기존 40초 필드 호출 상한은 바꾸지 않는다. 지연은 기록하되 이번 단계의 채택 기준으로 쓰지 않는다. NVIDIA HTTP 어댑터의 실제 시간 제한 특성은 별도 관찰한다.

## 검증

- 모의 Provider 테스트에서 모든 단계가 지정 NVIDIA 모델로 가고, 기본·Solar 선택자 모드의 요청이 변하지 않으며 잘못된 모델·키·응답 모델은 거부된다.
- 최소 합성 1건으로 응답 계약을 확인한 다음 고정 PRD 5건을 한 번 실행한다. Solar 선택자 실행은 40초 조건이었으므로 완료/확인 필요/실패와 정답 지표를 병렬로 보여도 모델만의 효과로 비교하지 않는다. 가능하면 동일한 긴 기한에서 Solar도 다시 실행한다. 확률적 별도 응답 차이를 인과 효과로 단정하지 않는다.
- 검토 응답이 미완료로 끝나면 원본 응답을 보관하지 않고 숫자형 출력 토큰 사용량·상한을 관측한다. 상한이 원인으로 확인되면 평가 전용 출력 한도를 명시적으로 늘려 1건을 재시험한다. 기본 서비스 출력 한도는 유지한다.
