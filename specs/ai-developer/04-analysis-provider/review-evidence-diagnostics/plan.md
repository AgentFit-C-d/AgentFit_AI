# 구현·검증 계획

1. 기존 `EVIDENCE_LINES` 발생 지점과 안전 진단 전달 경로를 확인한다.
2. 분류별 실패 테스트를 먼저 추가하고, 선택형 검토 변환기에서 고정된 안전 오류 코드로 분기한다. 허용 목록과 기존 오류 계약 테스트를 갱신한다.
3. 세 실패 사례를 안전 진단만 남기는 재현 도구로 실행해 실제 발생 유형을 기록한다. 세 사례에서 재현되지 않으면 합성 20건을 선택형 계약으로 한 번 더 실행한다.
4. 확인된 한 유형만 테스트 우선으로 수정한다. 기존 의미 검증과 공개 Profile은 유지한다.
5. 합성 20건 비교, 전체 테스트, 산출물 보안 점검을 실행한다. 결과와 미해결 문제를 `validation.md`에 기록하고 기능 브랜치에 관련 파일만 commit/push한다.
