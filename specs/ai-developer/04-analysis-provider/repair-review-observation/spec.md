# 수정/검토 분리 관측
모델·프롬프트·분석 계약은 바꾸지 않는다. 평가 도구에서 최초 초안, 원문 수정 직후, 재검토 입력을 같은 고정 골드로 채점한다.
골드/정답은 모델 입력에 넣지 않는다. 성공 Profile/인용/추론을 저장하지 않고 일치 여부·필드명·개수만 보존한다.
대표 실패 Q001/Q002/Q004/N004 네 건을 고정한다: 복수동작, 서로 다른 요청/처리, 명시적 부재, 특정 거부+채택.
원문 수정 직후 정답인데 재검토가 거절하면 검토 오거절, 정답이 아닌데 통과하면 오통과로 구분한다.
관측된 실행만 판정하며 지난 실행 결과를 소급 수정하지 않는다.

## 관측 이후 승인된 목표 내 후속 실험
진단에서 실제 수정 오답과 검토 오통과가 분리 확인됐다.
원문 수정 단계의 프롬프트에 일반 예시를 더한 단일 변수 비교를 진행하고,
효과를 보인 동일 예시를 repair_examples=True 옵션으로 연결한다.
기본False이며 공개Profile/스키마/모델/예산/다른 단계는 유지한다.
모델이 예시 내용을 문서 사실로 복사하면 기존 원문 인용 검증으로 실패해야 한다.
