# 의미 판단과 사용자 확정 분리

2026-10-01 사용자 요청에 따른 오탐 우선 수정. 기존 목표·품질 기준과 공개 Profile/OpenAPI를 유지한다.

## 실제 원인

- 원문 해시 `5d26fe9a49507c3937d1a7950e0c4e620b1db08c741f8a36b98a83c90529e87b`의 Documenso README에서 셀프호스팅/소스 확인 안내(C019), 가입 권유(C026)가 features/confirmed로 분류됐다. ID는 진단 자료에서만 사용한다.
- `capability-occurrences-full-v1` 추적에서는 두 오탐이 후속 검토에서 제거됐으나 PDF 서명·열람·수정·결제 등 정상 후보도 제거됐다. `classification-full-batch15-v1`은 분류만 실행했으므로 저장 오탐의 증거가 아니다.
- 분류 계약은 id/field/status만 검증한다. 원문 위치 검증은 사실의 대상·시점·채택 여부를 검증하지 않는다.
- confirmation-v2는 항상 사용자 확인을 요구한다. mock finish는 DRAFT만 저장한다. 사용자 PATCH에서만 CONFIRMED를 만든다. 실제 Spring의 잘못된 확정은 관측하지 못했다.
- mock은 문서 출처를 보존하지만 모델 판단과 사용자 승인 당시 이력을 독립된 저장 기록으로 제공하지 않는다.

## 변경

1. NVIDIA 후보 경로에 근거를 갖춘 의미 분류를 연결한다. 전체 원문과 후보별 위치를 제공하고 대상 프로젝트, 현재 범위/과거/미래, 긍정/부정, 채택/검토, 제품 사실/기타를 각각 판단한다. 확정된 요구사항의 구현 예정은 미확정 제안과 구별한다.
2. 지지·상충 근거는 원문 인용과 0부터 시작하는 등장 순서로 반환한다. 서버가 위치를 계산한다. 후보와 연결되는 유효한 지지 근거, 모든 긍정 축, 상충 검토 완료 및 상충 근거 없음이 갖춰져야 모델 확정 제안으로 허용한다. 애매한 축/불충분 근거/상충은 확인 필요, 명백한 부정·타제품·과거·검토안은 확정에서 제외한다. 원문 단어만 발견됐다는 사실은 이 조건을 대신하지 않는다.
3. 모델의 원래 status와 서버 결정은 독립된 modelDecisions에 남긴다. 확인 필요 후보는 이 기록에서 보존하고 해당 필드에 확인 질문을 만든다. 기본 Profile 데이터에 미확정 사실을 넣지 않는다. 모든 필드 일괄 삭제/확인 요구로 오탐을 줄이지 않는다.
4. AI 내부 confirmation-v2에 선택적 modelDecisions를 추가하고 HTTP/gateway/mock까지 검증·전달한다. 외부 공개 OpenAPI는 변경하지 않는다. 사용자 승인 기록은 인증된 사용자·저장 버전·참조 초안 버전·필드별 수정 여부·모델 판단 스냅샷을 별도로 유지한다. 원문 출처 DOCUMENT와 승인 주체 USER는 다른 개념이다.
5. 사용자 PATCH가 유일한 확정 작업이며 모델 응답의 confirmed가 사용자 확정을 생성할 수 없다. 저장 실패·권한·버전 충돌은 승인 기록도 원자적으로 보존한다. 재분석으로 과거 승인 기록을 바꾸지 않는다.

## 검증과 한계

- 실제 실패 후보와 정상 후보를 먼저 고정하고, 일반화된 타제품·과거·부정·검토안·확정 요구사항·동일 단어 반복·상충 사례를 함께 검사한다. 서비스 코드에 문서명/ID/특정 문구 예외를 넣지 않는다.
- 비교 지표: 잘못된 확정, 정상 확정 누락, 확인 필요 후보 수, 필드 질문 수, 실패/호출 수. 로컬 주입 회귀와 실제 API 결과를 구별한다. 기존 gold/원본 출력/평가 기준을 수정하지 않는다.
- NVIDIA는 사용자 확인된 무료 엔드포인트의 DeepSeek 4.1 Flash만 이번 비교에 사용한다. 최대 12호출, 재시도 0, 호출당 600초, 전체 최대 120분. 호출마다 승인 만료와 범위를 검사하며 한도·과금·인증·공급자 오류시 중단한다. 코드/입력/정답 고정 후 실행한다.
- 모델이 모든 의미 축과 근거를 함께 잘못 판단하는 가능성은 남는다. 실제 Spring/DB/UI, 사람 검토 부담, 새 기획서 일반화는 별도 미검증이다.

## 2차 비교 — 첫 결과 보존 후 범위 판단 보완

1차 비교 12호출/8요청 완료: 실제 후보 오확정 3→1(각 반복), 누락3→2이나 합성 정상 누락0→2, 한 반복 질문4→10. 원인은 다른 제품/과거 기술/선택적 로컬 도구를 현재 제공 사실과 상충한다고 보고, 판단을 먼저 긍정으로 채운 응답이다.
원래 판정 규칙·정답·후보·모델은 그대로 두고 근거를 출력 앞에, 최종 status를 마지막에 배치한다. 의미 축 정의와 같은 대상/시점/결정의 논리적 상충 조건을 명시한다. 유사 문구/ID를 검사하는 서비스 규칙은 추가하지 않는다. 1차 코드 스냅샷·결과는 보존한다.
2차도 같은 무료 모델, 최대12호출/재시도0/요청당600초/전체7200초. 합계 최대24호출. 실패·보류·누락 분모와 출시 기준은 유지한다.
