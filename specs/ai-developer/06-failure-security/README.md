# 실패와 보안 경계

- Provider 실패·거절·구조 오류·근거 부족을 안전한 오류로 분류한다.
- Secret 외부 전달·로그 노출과 문서 지시 실행을 막는 검증 사례를 다룬다.
- 업로드 원문·추출문의 별도 미보관과 재분석 시 기존 확인 Profile 보존을 Full Stack A와 검증한다. 실패 건에서 수신한 LLM 원본 응답만 최대 7일 진단용으로 보관하며, 정상 응답·일반 로그·공개 API에는 남기지 않는다.
- FastAPI는 오류 분류·진단 응답 전달 경계를, Spring Boot는 PostgreSQL 저장·만료·프로젝트 삭제를 책임진다. 기존 T031–T032, T034는 새 Plan·Tasks에서 재배정한다.
