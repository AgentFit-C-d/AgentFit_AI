# 검증 기록

- TDD: 동시 수용 제한과 느린 업로드 테스트가 `create_app` 설정 인자 부재로 먼저 실패한 뒤 구현했다.
- TestClient 병렬 요청: 첫 분석이 실행 중일 때 두 번째는 body를 읽지 않고 `503 SERVICE_BUSY`, `Retry-After: 1`을 반환했다. 첫 요청 종료 뒤 세 번째 요청이 수용됐다.
- ASGITransport 느린 body: 1초 업로드 기한 초과가 408이고 이후 요청이 수용됐다. 분석 예외 후에도 슬롯이 재사용됐다.
- 독립 리뷰에서 응답 객체 전송 전에 슬롯이 반환되는 결함을 발견했다. ASGI send를 멈춘 테스트에서 제한값 1인데 다음 요청이 200으로 수용되는 실패를 재현했다. 수정 후 전송 중 503, 전송 완료 후 200이다.
- 잘못된 동시 수용 수·업로드 기한 설정은 시작 시 실패했다.
- 전체 AI 테스트 484건 통과. 기존 평가 CLI의 예상된 `--live required` 출력은 있었고 종료 코드는 0이었다.
- Uvicorn 로컬 TCP smoke에서 health, 인증 거절, 문서 분석 응답이 통과했다.
- 수정본 독립 재검토에서 Critical/Important 결함은 발견되지 않았다. 리뷰어는 테스트를 독립 실행하지 못했으며, 위 테스트 결과는 작업 환경에서 실행한 기록이다.

## 남은 제약

슬롯은 FastAPI 프로세스 단위다. Spring 연결이 끊긴 뒤 시작된 동기 분석을 즉시 취소하지는 못한다. PDF worker의 OS 메모리 제한도 아직 없다.
