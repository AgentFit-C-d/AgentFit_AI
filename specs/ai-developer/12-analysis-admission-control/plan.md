# 구현 계획

1. `create_app` 팩토리에 프로세스별 동시 수용 수와 업로드 기한을 설정한다. 기본값과 환경 변수는 시작 시 검증한다.
2. 인증·헤더 검증 후 비차단 semaphore를 획득한다. body·추출·분석·JSON 응답 생성 중에는 엔드포인트가 슬롯을 소유한다. 반환된 응답 객체가 ASGI 전송 완료·중단 시 `finally`로 반납하고, 응답 객체를 만들지 못한 경우 엔드포인트가 반납한다.
3. body 읽기만 `asyncio.timeout`으로 제한해 느린 업로드를 408로 처리한다.
4. 테스트를 먼저 작성해 병렬 수용 제한, 슬롯 재사용, 느린 body 기한 실패를 재현한다. 독립 리뷰에서 발견한 ASGI 전송 중 조기 해제도 실제 ASGI send 대기 테스트로 재현한다. 구현 후 전체 AI 테스트·로컬 HTTP·diff를 검증하고 리뷰 후 push한다.
