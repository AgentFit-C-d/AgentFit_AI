# 로컬 OCR 기획서 변환 실험 계획

**Goal:** 이미지 속 한국어/영문 텍스트와 표 관계를 복구할 수 있는지 확인하고 원문 대응이 있는 검토 자료를 만든다.

**Spec:** `specs/ai-developer/local-ocr-document-preparation/spec.md`

**실행:** 직접 로컬 실험. 임시 코드는 제품 코드가 아니며 별도 scratch에 보존한다. 사용자 자율 승인에 따라 추가 승인 없이 실행한다.

## 범위와 상한

- 추론 API·개인 문서 외부 전송: 0회. 실제 기획서는 기존 공개 후보05/06/07/08만 로컬 변환한다.
- 모델 준비: 공개 고정 URL 다운로드 최대 4파일·파일당64MiB·60초·재시도0. 전체 준비300초. 다운로드 대상과 해시를 먼저 기록한다.
- 합성 PDF 2개: 이미지 전용 표와 네이티브 텍스트+이미지 혼합. 각 변환180초, 초기 1회. 실패 시 원인 확인 후 설정 수정은 최대1회이며 처음 결과를 보존한다.
- 실제 PDF 05/06/07: 각각180초·1회. 07은 완결된 초기 기획서 구간(원본10~18쪽)을 사용하고 원본 페이지 대응을 기록한다.
- DOCX08: OOXML 표 변환60초, 내장 그림 OCR 각각60초·9개·1회. 전체 로컬 실험1800초. 실패는 고정 코드와 미완료 상태로 남긴다.
- 서비스 코드/의존성 수정0. 기존 `E:/AgentFit/tmp/grounding-venv`에서 Docling/RapidOCR/Torch를 사용한다. DOCX/PDF 합성 자료 작성과 OOXML 읽기는 번들 Python을 사용한다.

## 미리 확인할 위험

표 일부가 인식돼도 상태 열이 다른 기능에 붙을 수 있다. 반복 텍스트가 한 번으로 합쳐질 수 있다. OCR이 한국어를 잘 읽어도 영문 기술명을 바꿀 수 있다. 네이티브 글자와 OCR 결과가 중복될 수 있다. 원문에 없던 문장을 LLM으로 보정하지 않고 각 문제를 원문과 대조해 기록한다.

## 2026-10-01 실행 중 판정과 독립 작업

합성 v2는 두 변환이 종료됐지만 품질 0/2였다. 초기 설정 수정 1회 상한을 사용했으며 이 실험의 추가 OCR 실행은 중단한다. PDF05/06/07·DOCX 그림9개는 미실행으로 남긴다. 원문 자료나 기대값을 바꾸지 않는다.

OCR과 독립적인 DOCX OOXML 구조 추출은 진행한다(기존 60초/1회 상한). 원문 순서·표 셀/병합·그림 관계·헤더/푸터를 로컬 JSON으로 기록하고, 텍스트 노드 및 그림 참조가 보존되는지 확인한다. 그림 속 글자·화살표 의미·전체 페이지 배치는 미검증이다. 이 산출물도 model_evaluation_allowed=false, human_reviewed=false다.

저장된 합성 Docling JSON에서 전체 content layer를 내보내는 진단은 추론 없이 실행한다. 최초 출력 및 판정을 덮어쓰지 않으며, 머리말 누락과 OCR 오인식의 원인을 구분하는 근거로만 사용한다.
