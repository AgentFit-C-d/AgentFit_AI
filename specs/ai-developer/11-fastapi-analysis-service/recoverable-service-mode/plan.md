# 구현 계획

1. 설정 모드와 Worker 선택, 프로세스 결과 계약, ASGI 응답을 각각 실패 테스트로 고정한다.
2. 서비스 모드를 앱 생성 시 검증하고 복구 모드만 프로세스 입력에 표시한다.
3. Worker에서 선택형 분석기를 실행하고 프로세스에서 초안·실패 결과를 정해진 키와 안전 코드로 검증한다.
4. 관련 및 전체 테스트, 로컬 HTTP 가짜 Provider 실험을 수행한다. 서비스 기본 경로와 외부 API 호출은 변경하지 않는다.
5. 검증 결과와 미완료 Spring 계약을 기록해 `feature/recoverable-service-mode`에 push한다.
