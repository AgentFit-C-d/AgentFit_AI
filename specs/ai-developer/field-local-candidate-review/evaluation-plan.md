# 고정 후보의 필드별 검토 비교

## 사전 등록

- 종류: 검토 단계만의 진단. 추출·분류 호출0, 제품 전체 정확도 평가가 아니다.
- 순서: PUBLIC-01, PUBLIC-07, SYNTHETIC-01 각1회.
- 원문·grounded 후보·classified 라벨: 기존 `capability-occurrences-full-v1`의 완료 trace를 검증해 사용한다.
- 합성 자료: 기존 `runtime-purpose-review/mixed-synthetic.json`의16개 후보. 정답은 부모 평가에만 사용하고 모델에 전송하지 않는다.
- 모델: `deepseek-ai/deepseek-v4.1-flash`, 무료 확인된 NVIDIA endpoint만. 모델 변경 없음.
- 동결: 현 코드·원문·기존 gold·trace·합성·실행기·무료 확인 파일의 hash를 검사한다. 이전 결과와 gold는 수정하지 않는다.
- 실행기: `.superpowers/sdd/plan-field-local-candidate-review/review_probe.py`. 실행 전 안전 테스트6개를 확인한다.
- 출력: `E:/AgentFit/output/independent-profile-v1/field-local-candidate-review-v1`에 새로 생성하며 기존 경로면 거절한다.

## 예산과 중단

요청당1800초/31호출, 전체5400초/93호출, 재시도0. 호출마다 무료 확인 유효성과 허용 모델을 검사한다. 한도·제공자·계약 오류 시 해당 요청을 실패로 기록하고 다음 요청을 실행하지 않는다. 부모 제한시간 초과 시 실제 완료 호출 수는 미확인으로 구분한다. 키는 메모리와 자식 stdin으로만 전달하며 원문·원본 모델 응답은 결과에 기록하지 않는다.

무료 확인의 `max_model_calls`는 실험 예약 상한이며 계정 잔여량이 아니다. 확인 자료의 만료일을 연장하지 않는다. 실패 재시도·유료 대체·충전은 없다.
