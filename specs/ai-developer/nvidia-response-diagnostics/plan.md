# 구현 계획

1. 기존 전송·조립·저장 경로를 확인하고 진단 부재 회귀 테스트를 먼저 실패시킨다.
2. 오류 위치만 부착하는 계측과 제한/민감 정보 제거 도구를 구현한다.
3. 워커 실패 봉투와 비교 finished 저장에 연결한다. 기존 응답 검증식은 유지한다.
