# 제품 용도 규칙 비교 계획

**분류:** 제한 조사(spike), 직접 실행. 자율 설계·진행 승인 유지.

**Spec:** [spec.md](spec.md)

- [ ] 공통 prompt.txt와 합성 입력·기대 ID를 결과 보기 전에 고정한다. 특정 제품이나 임시 gold 값을 지침에 넣지 않는다.
- [ ] 직전 검증된 replay 실행기를 재사용하되 명시적 variant/case로 새 출력만 만든다. 불변 입력과 응답 계약을 유지하는 payload 사본에 설명만 추가한다.
- [ ] 외부0검증: 기존 variant payload 동일, 새 variant system 설명만 변경, 반복 인용의 별도ID, 개발·부정·타제품 기대값과 모델 입력 분리, 무료/실패 중단의 기존 검증 유지. 로컬180초 상한.
- [ ] 사전 등록6요청을 순서대로 수행한다. 최대78호출/7200초/재시도0, 요청1200초. 실패면 그 지점에서 중단한다.
- [ ] 원문별 유지/제외·이전 대비 변화·사유·합성 실패·시간·호출을 보고한다. 검증된 결과를 commit/push한다.

최종 산출물은 근거 있는 채택/보류 판단이다. 제품 코드 변경 및 기본 적용은 이 제한 조사에 포함하지 않는다.
