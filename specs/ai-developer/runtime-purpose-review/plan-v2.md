# 필드 범위를 명시한 후속 비교

v1 실험의 배포 근거 제외 회귀에 따라 한 변수만 바꾼다: 공통 설명의 적용 범위를 features로 명시한다. 실제 코드·공개 계약은 바꾸지 않는다. 자율 계획·직접 실행 승인 유지.

1. 기존 prompt.txt, 합성 자료, 출력은 보존한다. prompt-v2.txt와 mixed-synthetic.json을 사전 등록한다. 새 합성은 기존12항목에 frontend/backend/database/deployment의 명시적 채택 사실4개를 추가한다.
2. PUBLIC-01/PUBLIC-07 고정 snapshot을 v2로 각2회 검토한다. 고정 혼합 합성을 baseline/v2 각1회 비교한다. 기존 baseline과 v1 결과를 각각 보고한다.
3. 최대6요청78호출/7200초, 요청1200초/재시도0. 동일 무료 검증/중단/비밀 보호/동결 검증기를 재사용한다. 외부0 사전 검증180초 상한.
4. 기능4개 복구·안내2개 제외·PUBLIC-07 기능 유지 외에 Docker의 명시적 배포 근거 C113/C115 유지, 혼합 합성16항목 기대 판정과 후보에서 빠진 project_name 누락 검출을 확인한다. 위반 또는 다른 필드의 신규 유효 사실 손실이면 채택 보류한다.

모델 사유와 에이전트 합성 정답은 사람 검토를 대체하지 않는다. 유효할 경우 별도 구현 계획으로 연결하며, 이 실험 자체를 서비스 적용이나 일반화 완료로 계산하지 않는다.
