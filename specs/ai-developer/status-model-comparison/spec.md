# 정의 통일 지침의 모델 비교 명세

2026-10-02 KST · 상태: 계획만 작성, 실행 승인 전 · 기준 commit `224a0d7`.

## 목적과 범위

현재 정의 통일(US) 지침과 동일한 32개 후보를 고정하고 DeepSeek V4.1 Flash와
GLM 5.3 한 모델을 비교한다. 모델별 지침 튜닝 없이 의미 분류·부정·불확실성·근거 선택 차이를 관찰한다.
이번 요청의 산출물은 입력 고정 기록과 비교 계획이다. 새 모델 호출, 실행기 구현,
서비스 적용, Spring 변경, 큰 goal 재개는 하지 않는다.

## 고정 기준

- 기준선: `E:/AgentFit/output/status-definition-v1/calls/03~06-request.json`의 실제 US 요청 4개.
  UC 또는 이전 U+C 요청으로 되돌리지 않는다. 원본 파일별 정확한 경로는 `input-freeze.json`에 기록한다.
- 각 요청의 전체 system, user, response_format, 생성 인자를 보존한다.
  비교군의 유일한 payload 차이는 `model` 값이다. 지침 추가·삭제, 모델별 예시, 스키마 완화 금지.
- D: `deepseek-ai/deepseek-v4.1-flash`. G: `z-ai/glm-5.3`.
- endpoint: `https://integrate.api.nvidia.com/v1/chat/completions`.
- Fluent Reader(FR) 16개, LocalSend(LS) 16개. 주 점수 30개, 정상 긍정 16개,
  제외 정답 14개(범위 밖 13개 + 명시적 부정 LS07 1개).
- FR16·LS15는 기존 사람 검토 항목으로 주 점수에서 제외한다. 정답 초안과 원문 위치를 수정하지 않는다.
- 지침의 confirmed/irrelevant/negated/tentative 정의, 원문 단위 ID 방식,
  서버 보류 처리, 점수 함수, 원시 field/status 보존을 유지한다.
- 전체 원문 + 후보 앞뒤 240자 + 해당 문서의 모든 줄 단위 레지스트리를 두 모델에 동일하게 제공한다.
  문서 재다운로드, 축약, 검색, 임베딩, 후보 재추출, 정답·이전 판정의 모델 입력 포함은 금지한다.

## 현재 확인 수준

GLM 5.3을 **조건부 비교 후보**로 선정한다. 공식 공개 페이지의 무료 엔드포인트와
문맥 한도는 확인했지만 계정 무료 잔량 및 현재 strict JSON schema/추론 끄기의 호스팅 지원은 미확인이다.
근거와 한계는 `model-check.md`에 분리한다. 일반 OpenAI 호환 표기만으로 모든 옵션 지원을 단정하지 않는다.

만료된 기존 무료 확인 기록은 실행 허가 근거로 사용하지 않는다. 과거 freeze의 무결성 확인에
해당 파일 해시가 포함돼 있어도 유효성 연장·재사용이 아니다. 실행하려면 두 모델·정확한 endpoint에
대한 새 계정 무료 확인과 별도 실행 승인이 모두 필요하다.

## 실행 한도 제안

- 한 쌍: 모델별 4회, 총 최대 8회. 각 문서 8후보 × 2배치, 반복 1회, 동시 실행 1개.
- 재시도·수정 호출·추가 호환성 테스트·유료 대체 0회. 첫 GLM 본 배치를 호환성 검사로도 사용한다.
  이 검사는 향후 실행 승인에 명시적으로 포함되어야 하며 별도 무료 확인 없이 호출할 수 없다.
- 요청별 600초, 최초 요청 전부터 결과 수집까지 전체 5,400초(90분).
  네트워크·큐 대기도 포함하고 전체 남은 시간을 요청 제한에 반영한다.
- 무료 여부/잔량 미확인·만료, 402/429, 그 밖의 호출 실패, 모델 ID 불일치,
  응답 파싱/스키마 실패, 문맥 초과, 출력 잘림, 해시 변경 시 남은 호출을 모두 중단한다.
  인용 ID 결함은 원시 응답을 보존해 기존 평가 지표로 집계한다.
- 중단 후 재시작으로 한도를 초기화하지 않는다. 시작한 시도는 실패·타임아웃이어도 1회로 센다.

## 평가와 해석

동일 정답에 대한 모델 오확정과 서버 통과 오확정을 분리하고 정상 누락, 올바른 제외,
정상 후보의 보류, 전체 보류, 불확실한 2건의 보류, 인용 결함, 호출 수·시간을 문서별로 보고한다.
LS07의 field/negated 유지, FR16의 보류, LS15의 지지·상충 가능 근거 선택을 개별 기록한다.
LS15의 제외를 올바른 제외로, 보류를 정상 누락으로 주 점수에 편입하지 않는다.

전부 보류해 오확정만 줄인 결과는 개선으로 인정하지 않는다. 오확정 감소와 정상 보존·올바른 제외·
불확실성 보존을 함께 비교하며 항목 사이 상충은 그대로 보고한다. 한 쌍의 결과로 통계적 우월성이나
새 문서 일반화, 후보 추출 재현율, 서비스 안정성을 주장하지 않는다. 서비스의 자동 적용은 없다.
