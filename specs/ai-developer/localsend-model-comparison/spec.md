- 진단 구현 기준 커밋 f0bdc04. 현재 소스와 실험 실행 코드를 실행 전 SHA-256으로 동결한다.
- 기존 status-model-comparison-v1 package에서 LS 문서·16개 후보·정답·원문 단위·요청을 그대로 사용한다.

- 지침·스키마·옵션·문맥·정답·정규화·서버 판정·채점은 동일하다.

  과거 실행 예산을 재사용하지 않고 이번 4회만 승인 기록에 반영한다.

  모델 오확정·서버 통과 오확정·정상 누락·올바른 제외·보류·인용 결함·시간을 보고한다.
