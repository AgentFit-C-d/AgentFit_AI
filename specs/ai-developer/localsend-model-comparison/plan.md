# 실행 계획

1. 기존 package와 동결 입력·정답·판정 코드를 대조한다.
2. 기존 호출 게이트를 그대로 상속하는 LS 전용 4회 실행기를 추가하고 합성 응답으로
   상한·순서·첫 실패 중단·진단 보존·동일 판정·만료 거절을 검증한다.
3. 실행 코드 커밋 후 현재 코드/입력 해시와 이번 신규 승인 기록을 새 폴더에 동결한다.
4. 무료 NVIDIA 엔드포인트로 지정된 네 배치만 순차 호출한다. 실패 후 변경/재시도하지 않는다.
5. 성공/미검증을 구분하고 LS07·LS15 결과 또는 실패 진단을 기록·push한 뒤 종료한다.
