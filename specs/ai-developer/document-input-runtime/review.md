## 중요한 지적 및 수정

성공 원문 누출 검사가 JSON 문자열의 이스케이프와 원문의 실제 줄바꿈을 서로 비교해 CRLF/LF 원문 저장을 놓쳤다. 제품 누출을 발견한 것은 아니다.

- 수정 전: MockStore.finish에 합성 Markdown 원문 저장을 주입했는데 기존 시험이 성공. 감지 실험 exit1 `PRIVACY_ASSERTION_MISSED_SYNTHETIC_SOURCE`로 재현.
- 수정: 원문 검색 문자열도 같은 JSON 인코딩으로 변환해 검사. 단일 행 키 검사도 유지.
- 수정 후: 동일 실험 exit0 `MUTATION_DETECTED`, 실제 저장된 원문을 감지했다. 정상 대상3건 12.667초 통과.
- 수정 후 전체 회귀 검사와 정확한 push SHA의 CI는 validation.md에 기록한다.
