# 구현 계획

1. 원본 실행을 읽어 필수 파일 hash manifest와 압축 회귀 fixture를 만든다. 원본 불변을 확인한다.
2. 거부 조건과 분류 완료 경계에 대한 실패 테스트를 작성한다.
3. diagnostic_tools에 read-only 검사기와 기존 검토 함수를 이용하는 계획 생성기를 추가한다. 서비스 파일은 수정하지 않는다.
4. 합성 전송기와 단일 claim/합산 예산 검증을 추가한다. 외부 socket·프로세스 전송을 차단한다.
5. 신규 검사, 기존 v2/v3·실행기 회귀 및 가능한 전체 오프라인 suite를 실행한다. 독립 리뷰와 기록 일치 점검 후 결과 보고.

실제 전송0, 재시도0. Git 외부 push도 이번 네트워크 차단 범위에서는 보류하며 로컬 feature 브랜치에 기록한다. 예상 실제 재개는 성공 검토 결과에 따라 달라지는 요청까지 따로 표시한다.
