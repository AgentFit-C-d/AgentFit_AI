# 임시 정답의 의미 검토 쟁점

이 문서는 사람이 검토할 쟁점을 기록한다. gold-v1.json을 수정하거나 기존 점수를 다시 계산하지 않는다. 아래 판단은 에이전트의 검토 의견이며 확정 정답이 아니다.

## PUBLIC-01 Documenso

- 기능 U017은 디지털 서명의 바람직함을 서술하는 소개 문장에 있다. 제품 소개 전체 맥락에서 구체적인 제품 기능을 뜻하는지, 일반적인 당위 서술인지 판단이 필요하다.
- 기능 U018~U023은 기술 목록의 Email Templates, Internationalization, PDF Signatures, Viewing PDFs, PDF manipulation, Payments 용도다. 단순 라이브러리 이름과 구체적 제품 동작의 용도를 구분해야 한다. 도구만으로 기능을 추론하는 것과 원문이 직접 용도를 명시하는 것은 다르다.
- backend U010 Prisma는 여러 근거 위치를 가진다. 일부 위치는 URL/배지이고 **적절한 ORM 기술 목록 위치도 포함돼 있다**. URL만으로 만든 정답이라고 단정하면 안 된다. 다만 explicit-v1의 backend 언어·프레임워크·런타임 정의에 ORM이 들어가는지는 별도 기준 합의가 필요하다.
- backend의 PDF 라이브러리 항목도 server-side 구현 언어·프레임워크·런타임 정의와 차이가 있을 수 있다.
- Node.js와 Postgres 일부 근거는 Development/Requirements의 로컬 실행 요구사항이다. 이 정보가 제품 채택 기술까지 뒷받침하는지 주변 실행 지침과 함께 판단해야 한다. 개발 문맥이라는 이유만으로 무조건 제외하지 않는다.

## PUBLIC-09 Vikunja

기능 세 항목은 Vikunja Pro의 admin panel, audit logs, time tracking 안내다. 무료 제품과 같은 제품군이더라도 분석 대상 판본의 범위를 먼저 정해야 한다. 모델의 제외를 무조건 누락 오류로 채점하지 않는다.

## PUBLIC-07 Docmost

명시적 기능 목록11개는 비교적 분명하다. 긴 설명과 짧은 이름이 함께 출력되는 경우 같은 의미 단위가 중복되는지 검토한다. 근거가 각각 정확하다는 사실만으로 사용자에게 유용한 대표 기능 목록임이 입증되지는 않는다.

## 처리 원칙

사람 검토 전에는 위 쟁점을 이유로 gold를 유리하게 바꾸거나 품질 기준을 낮추지 않는다. 기존 결과를 보존하고, 판정 근거·범위·수정 사유가 확인되면 별도 버전으로 정답을 갱신한다.
